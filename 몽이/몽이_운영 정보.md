# 운영 정보

**서비스명**: 클린루프 (CleanLoop)
**문서 목적**: 대시보드 카테고리, 청소 방법·도구 콘텐츠, 주기 계산 로직, 파트너 업체·가격 데이터의 운영 기준 문서
**상위 문서**: 클린루프 기획서 v2
**주의**: 업체·가격 데이터는 MVP용 정적 큐레이션 데이터이며, 발표·서비스 시점에 실조사로 갱신한다 (정직성 원칙)

## 2. 청소 도구·방법 정보 (가이드 콘텐츠 운영 기준)

### 2.1 가이드 콘텐츠 표준 구조 (해결 플로우 STEP 3)

모든 가이드는 동일한 틀로 작성한다:

```
① 원인 한 줄 (왜 생기는가)
② 난이도 + 예상 소요시간 (진입 장벽 낮추기 — 톤앤매너 문서 참조)
③ 필요한 도구·세제 목록 (보유 여부 체크 → 없으면 STEP 4 구매 연결)
④ 단계별 방법 (3~5단계, 한 단계 한 문장)
⑤ 안전 주의사항 (필수 고지)
```

### 2.2 대표 이슈별 도구·방법 요약

| 이슈 | 필요 도구·세제 | 방법 요약 | 난이도 / 소요 |
|---|---|---|---|
| 타일 곰팡이 | 곰팡이 제거제(락스계), 솔, 고무장갑, 마스크 | 제거제 도포 → 30분 방치 → 솔질 → 물로 헹굼 → 환기 | 하 / 15분 + 방치 |
| 실리콘 곰팡이 | 곰팡이 제거 젤, 키친타월 | 젤 도포 → 랩·타월 밀착 → 6시간+ 방치 → 제거 | 하 / 10분 + 방치 |
| 배수구 물때·냄새 | 배수구 클리너 또는 베이킹소다+구연산, 솔 | 부품 분해 → 클리너 투입 → 방치 → 솔질·헹굼 | 중 / 20분 |
| 세탁조 청소 | 세탁조 클리너 | 클리너 투입 → 세탁조 코스(고온) 실행 → 통 건조 | 하 / 5분 + 코스 |
| 가스레인지 기름때 | 주방 기름때 세정제, 스크래퍼, 극세사 천 | 세정제 분사 → 5분 방치 → 스크래핑 → 닦아내기 | 중 / 20분 |
| 이불 세탁 | 세탁망, 이불용 세제 (또는 코인워시) | 커버 분리 → 세탁망 → 이불 코스 → 완전 건조 | 하 / 10분 + 세탁 |
| 초파리 제거 | 초파리 트랩, 배수구 클리너 | 발생원(배수구·음쓰) 제거 → 트랩 설치 → 1주 관찰 | 하 / 10분 |

### 2.3 안전 고지 원칙 (위험 요소 대응: 정보 신뢰)

- **혼합 금지 경고 필수**: 락스(염소계) + 산성 세제 혼합 시 유독가스 발생 — 관련 가이드 모든 화면에 고정 노출
- 환기 필수 항목 명시 (락스계, 곰팡이 제거제 사용 시)
- 소재별 사용 제한 표기 (대리석에 산성 세제 금지 등)
- 모든 가이드는 게시 전 전문가 검수를 거친다

### 2.4 도구 가격비교 운영 (해결 플로우 STEP 4)

- 이슈별 필수 도구 1~3종에 대해 **다나와식 최저가 카드** 노출
- MVP는 정적 큐레이션: 주요 커머스(쿠팡, 네이버쇼핑, B마트) 기준 가격대를 수기 조사·주기 갱신
- 제휴 링크에는 제휴 배지 명시 (정직성 원칙)

## 3. 주기 계산 로직

### 3.1 기본 원리

사용자 입력 없이 상태를 자동 계산한다. 이것이 기존 트래커 대비 최대 차별점(선입력 비용 제거)이다.

```
기준선(anchor) = 마지막 완료일
  · 가입 직후: 가입 시점을 '집이 마지막으로 정돈된 날'로 간주
  · 이후: 해결 완료(SELF/PARTNER) 기록이 생길 때마다 갱신

경과율 = (오늘 - 기준선) / 권장 주기
```

### 3.2 상태 판정 규칙

| 상태 | 조건 | 대시보드 표시 | 인터랙션 |
|---|---|---|---|
| **정상** | 경과율 < 80% | 초록 체크 | 탭 불가 (불필요한 상호작용 제거) |
| **임박** | 80% ≤ 경과율 ≤ 100% | 노랑 점 | 탭 불가, 알림 채널로만 리마인드 |
| **지연** | 경과율 > 100% | 분홍 점선 | 탭 가능 → 해결 플로우 진입 |

### 3.3 완료 처리와 주기 갱신

```
해결 완료 (확인 절차 없음)
  → ResolutionLog 생성 (방식: SELF / PARTNER)
  → 기준선 = 완료일로 갱신
  → 다음 예정일 = 완료일 + 권장 주기 (RoutineTask 자동 생성)
  → 대시보드 카드 즉시 정상(초록) 전환
```

- **PARTNER 정기 서비스 예약 시**: 카드가 "처리됨" 상태로 전환되고, 주기는 해당 서비스의 반복 조건(예: 주 2회 수거) 기준으로 자동 갱신
- 사용자가 권장 주기를 수정할 수 있는 고급 설정은 중기 유료화 후보 (N주 단위, 계절별)

### 3.4 계절 보정 (단기 확장)

| 조건 | 보정 |
|---|---|
| 하절기 (6~9월) | 해충·쓰레기 주기 단축 (예: 해충 4주 → 2주) |
| 장마철 (6~7월) | 욕실·곰팡이 주기 단축 + 계절 카테고리 노출 |
| 동절기 (12~2월) | 결로·창틀 카테고리 노출 |

### 3.5 알려진 한계와 운영 방침

- "가입일 = 정돈된 날" 가정은 이미 오염된 집에서 가입하면 부정확하다 → 첫 완료 기록이 쌓이는 순간부터 정확해지는 구조이며, 초기 상태는 참고치임을 인지한 설계
- 알림은 항목당 주 1회 이하 (알림 피로 방지 원칙)

## 4. 청소 서비스·업체 정보 및 가격

> ⚠️ 아래 데이터는 **MVP 프로토타입용 정적 큐레이션 데이터**다. 가격·조건은 시연 시나리오 기준의 대표값이며, 실제 서비스 전 실조사로 갱신하고 화면에는 조사 시점을 표기한다.

### 4.1 파트너 카드 표준 스키마 (PartnerCard)

```
업체명 / 분야 / 서비스 범위 / 가격(또는 견적) /
반복 조건(정기 여부) / 평점·후기 수 / 가능 지역 / 제휴 여부(배지)
```

### 4.2 분야별 큐레이션 업체 (카테고리 매핑)

#### 쓰레기·수거 → 수거 서비스

| 업체 | 서비스 | 가격 (프로토타입 기준) | 비고 |
|---|---|---|---|
| 오늘수거 | 문앞 정기 수거 주 2회 | 15,900원/월 | 시나리오 B의 "가장 많이 선택" |
| 커버링 | 정기 수거 주 1회 | 9,900원/월 | 저가 옵션 |
| 로컬 수거팀 | 맞춤형 (대형 폐기물 등) | 견적 | 비정형 수요 폴백 |

#### 침구·빨래 → 세탁 서비스

| 업체 | 서비스 | 가격 (프로토타입 기준) | 비고 |
|---|---|---|---|
| 런드리고 | 비대면 수거·배송, 이불 세탁 | 이불 단품 1~2만원대 / 월 구독제 | 새벽 수거 |
| 세탁특공대 | 모바일 수거, 물세탁·드라이 | 품목별 단가제 | 단건 중심 |
| 크린토피아 | 지점 접수 + 수거 | 이불 1만원 미만~ | 최저가 폴백 |

#### 욕실·주방·바닥 → 가사청소 서비스

| 업체 | 서비스 | 가격 (프로토타입 기준) | 비고 |
|---|---|---|---|
| 미소 | 가사도우미 (시간제) | 4시간 5~6만원대 | 정기 할인 |
| 청연 | 전문 청소 (입주·특수) | 평형별 견적 | 대청소·곰팡이 심화 케이스 |
| 로컬 전문업체 | 부분 청소 (욕실 단품 등) | 견적 | 지역 커버리지 보완 |

### 4.3 노출·추천 규칙

- 분야별 **3~5개 카드만** 큐레이션 노출 (비교 피로 방지)
- 정렬 기본값: 사용자 선택 수 → 평점 순. 제휴 여부는 정렬에 영향을 주지 않는다
- 제휴 업체는 **'제휴' 배지 필수** (정직성 원칙)
- 실제 지연/임박 상태인 사용자에게만 업체 제안 노출 (광고 오인 방지)
- 커버 불가 지역: 업체 카드 대신 직접 해결 가이드로 폴백 (파트너 콜드스타트 대응)

### 4.4 파트너 품질 운영

- 입점 심사: 사업자 확인, 가격 공개 동의, 후기 정책 동의
- 후기 검증: 실제 예약 완료 사용자만 후기 작성 가능
- 클레임 처리: 불만 접수 채널 운영, 반복 클레임 업체 노출 제외
- 통신판매중개자 책임 범위 고지 문구를 예약 화면에 고정 노출
