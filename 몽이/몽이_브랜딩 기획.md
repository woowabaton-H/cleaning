# 브랜딩 기획

**서비스명**: 클린루프 (CleanLoop)
**문서 목적**: 브랜드 방향성과 톤앤매너를 정의해, 화면 카피·알림·마케팅 문구의 일관성을 지키기 위한 기준 문서
**상위 문서**: 클린루프 기획서 v2

---

## 1. 브랜딩

### 1.1 브랜드 미션

```
깨끗한 집은 의지가 아니라 시스템으로 유지됩니다.
클린루프는 그 시스템이 되어, 청소를 부담이 아닌 가벼운 일상으로 바꿉니다.
```

### 1.2 네이밍

- **클린루프 (CleanLoop)** = Clean + Loop
- '루프'는 제품의 핵심 구조 그 자체: 상태 확인 → 해결 → 주기 자동 갱신 → 다시 상태 확인으로 돌아오는 **끊기지 않는 순환**
- 한 번 청소하고 끝이 아니라, 시스템이 계속 돌아간다는 약속을 이름에 담는다

### 1.3 브랜드 성격 (Brand Personality)

| 성격 | 설명 | 아닌 것 |
|---|---|---|
| **다정한 동거인** | 옆에서 같이 사는 친구처럼 챙겨준다 | 감시하는 관리자, 잔소리하는 부모 |
| **재시작을 환영하는** | 밀린 것은 실패가 아니라 다시 시작할 지점 | 밀림을 부끄럽게 만드는 |
| **가볍게 등을 미는** | "해볼까요?" 한 마디로 시작하게 한다 | 죄책감·압박으로 움직이게 하는 |
| **정직한** | 제휴는 제휴라고 말한다 | 광고를 추천인 척 숨기는 |

### 1.4 브랜드가 지키는 약속

1. **사용자를 게으르다고 전제하지 않는다.** 청소가 밀리는 건 시스템이 없어서지, 사람이 문제여서가 아니다 (핵심 인사이트 2.3과 동일한 관점)
2. **압박하지 않는다.** 알림은 주 1회 이하, 지연 표시는 색상 변화로만. 빨간색·경고음·느낌표 남발 금지
3. **재시작 비용을 0으로.** 오래 방치했다가 돌아와도 사과할 필요도, 밀린 기록을 정리할 필요도 없다. 열면 지금 상태만 보인다

### 1.5 비주얼 방향 (상태 색상 체계)

제품의 상태 3색이 곧 브랜드 컬러 체계다.

| 상태 | 색 | 감정 설계 |
|---|---|---|
| 정상 | 초록 | 안심 — "지금은 아무것도 안 해도 돼요" |
| 임박 | 노랑 | 부드러운 환기 — 경고가 아니라 예고 |
| 지연 | **분홍** | 의도적 선택. 빨강(경고·실패)이 아니라 분홍(부드러운 초대)으로, 지연을 혼내지 않고 "여기부터 해볼까요?"로 읽히게 한다 |

## 2. 톤앤매너

### 2.1 한 줄 정의

```
다정함. 실패보다 재시작.
청소를 쉽게 할 수 있도록, 불편해하지 않도록.
```

듀오링고가 언어 학습에서 해낸 것을 청소에서 한다: **꾸준함을 요구하는 지루한 일을, 죄책감 없이 다시 돌아올 수 있는 가벼운 습관으로.**

### 2.2 보이스 원칙 4가지

**① 청유형으로 말한다 — "해볼까요?"**
명령("하세요")도 통보("해야 합니다")도 아닌, 같이 하자는 제안. 모든 행동 유도 문구의 기본형은 청유형이다.

**② 실패라는 단어를 쓰지 않는다**
'밀림', '실패', '못 했어요', '벌써 N일째' 같은 추궁형 표현 금지. 지연은 상태일 뿐이고, 상태는 언제든 바꿀 수 있다. 과거를 세지 말고 다음 행동을 가리킨다.

**③ 짧고 쉽게**
한 문장 한 메시지. 전문용어·한자어 대신 생활어. "위생 관리가 필요합니다" ❌ → "욕실, 슬슬 한번 볼까요?" ⭕

**④ 재시작은 축하로 맞는다**
오랜만에 돌아온 사용자에게 필요한 건 요약된 밀린 목록이 아니라 환영. 듀오링고가 스트릭이 끊겨도 "다시 만나서 반가워요"로 시작하듯이.

### 2.3 Do / Don't

| 상황 | ❌ Don't | ⭕ Do |
|---|---|---|
| 지연 알림 | "욕실 청소가 11일 지연되었습니다" | "욕실이 기다리고 있어요. 오늘 한번 볼까요?" |
| 임박 알림 | "곧 청소 기한이 만료됩니다" | "이불 빨래할 때가 다가와요. 주말 어때요?" |
| 완료 | "작업이 등록되었습니다" | "반짝반짝! 다음 주기는 제가 기억할게요" |
| 오랜만의 복귀 | "밀린 항목이 4개 있습니다" | "다시 만나서 반가워요! 딱 하나부터 시작해볼까요?" |
| 주간 클리어 | "모든 항목 완료" | "이번 주 클리어! 이번 주말은 그냥 쉬어요" |
| 업체 제안 | "전문 업체를 이용하세요" | "직접 하기 번거로우면, 맡기는 방법도 있어요" |
| 어려운 청소 | "세탁조 청소 방법 안내" | "세탁조 청소, 생각보다 간단해요. 3단계면 끝!" |

### 2.4 상황별 카피 가이드

**온보딩 (푸시 권한 사전 설득 화면)**
```
청소 주기, 저희가 대신 기억할게요.
꼭 필요할 때만, 일주일에 한 번 이하로 알려드려요.
```
→ 압박이 아니라 대신 기억해주는 것임을 먼저 약속하고 권한을 요청한다.

**해결 플로우 진입**
```
타일 곰팡이, 같이 해결해봐요.
15분이면 충분해요.
```
→ 소요시간을 먼저 알려 심리적 진입 장벽을 낮춘다.

**용품이 없을 때**
```
곰팡이 제거제가 없어도 괜찮아요.
지금 주문하면 내일 도착 — 주말에 딱 맞춰요.
```
→ '준비 부족'을 실패가 아니라 해결 가능한 다음 단계로 전환.

**외주 제안 (지연이 길어질 때)**
```
이건 좀 큰일이죠. 혼자 다 하지 않아도 돼요.
믿을 만한 업체 3곳을 골라뒀어요.
```
→ 외주를 '포기'가 아니라 현명한 선택으로 프레이밍. 제휴 배지는 항상 함께 노출.

### 2.5 금지 목록

- 죄책감 유발: "아직도 안 하셨네요", "N일째 방치 중"
- 위협·경고 톤: "위생에 심각한 문제가", 빨간 경고 아이콘
- 과잉 이모지·과잉 텐션: 한 메시지에 이모지 1개 이하
- 숨긴 광고: 제휴 항목에 배지 없이 추천처럼 노출 (정직성 원칙 위반)
- 재촉 연타: 같은 항목으로 주 1회 이상 알림

### 2.6 한 문장 리트머스 테스트

```
"3주 만에 앱을 연 사용자가 이 문장을 읽고,
 미안함이 아니라 '오늘 하나 해볼까'를 느끼는가?"
```
