# 클린루프 — 브랜딩 기획

작성일: 2026-07-09
범위: 브랜딩 / 톤앤매너

---

## 1. 브랜딩

### 1.1 브랜드가 해결해야 할 감정

이 서비스가 마주하는 사용자는 청소를 **못 하는** 사람이 아니라, 청소 앞에서 **막막해진** 사람이다.

| 사용자가 실제로 느끼는 것 | 기존 앱이 주는 것 | 클린루프가 줘야 하는 것 |
|---|---|---|
| "밀린 건 아는데 어디서부터인지 모르겠다" | 더 긴 체크리스트 | 지금 눌러야 할 카드 하나 |
| "이거 내가 할 수 있는 수준인가?" | 침묵 | 난이도와 기준선 |
| "또 못 했네" | 빨간 배지, 연체 표시 | "괜찮아요, 5분짜리부터 볼까요?" |
| "맡기는 건 좀 지는 것 같은데" | 언급 없음 | 택시·배달처럼 정당한 선택지 |

**브랜드의 첫 번째 임무는 죄책감을 걷어내는 것이다.**

### 1.2 브랜드 포지션

```text
클린루프는 잔소리하는 부모가 아니라,
집을 잘 아는 옆집 친구다.
```

- 감시하지 않는다. 상태를 보여줄 뿐이다.
- 채근하지 않는다. 지금 가능한 선택지를 놓아줄 뿐이다.
- 판단하지 않는다. 직접 하든 맡기든 같은 무게로 다룬다.

### 1.3 네이밍 체계

| 레이어 | 이름 | 역할 | 근거 |
|---|---|---|---|
| **서비스명** | **클린루프 (CleanLoop)** | 앱·회사·대외 커뮤니케이션 | `발견 → 해결 → 주기화 → 재발견`이라는 제품의 핵심 구조 자체가 이름이다. 기능이 늘어도 이름이 좁아지지 않는다 |
| **캐릭터/화자** | **보송이** | 알림 문구, 온보딩, 마스코트 | 초안의 `보송 매니저`를 흡수. '보송보송'의 촉감어 → 청소 후의 감각을 직접 지시 |
| **핵심 UI 자산** | **뽀득 스탬프** | 홈의 상태 카드 | '뽀득'은 깨끗이 닦였을 때의 소리. 점수가 아니라 감각으로 상태를 말한다 |
| **페르소나** | **김보송** | 내부 문서·발표용 | 브랜드 톤과 대상 사용자를 하나의 이름으로 묶는다 |

> **왜 '보송 매니저'를 서비스명으로 쓰지 않는가**
> ① '매니저'는 관리·감독의 뉘앙스가 있어 1.1의 '죄책감 제거'와 충돌한다.
> ② 청소 대행 인력을 직접 고용하는 서비스로 오해될 수 있다(우리는 중개자다).
> ③ B2B(숙박·임대관리)로 확장할 때 톤이 맞지 않는다.
> 반면 캐릭터 이름으로는 완벽하다. **부드러운 화자, 단단한 제품명**의 구성.

### 1.4 브랜드 메시지 계층

```text
[태그라인]      상태가 알려주고, 해결까지 이어준다.

[핵심 메시지]   깨끗한 집은 의지가 아니라 시스템으로 유지됩니다.
                그리고 그 시스템은, 상태를 보여주는 것에서 시작됩니다.

[기능 메시지]   등록하지 마세요. 밀린 것만 알려드릴게요.
                해결 방법부터 도구, 업체까지 한 화면에서.
                다 하면 다음 주기는 알아서 잡아둘게요.

[반론 대응]     맡기는 건 포기가 아니에요.
                늦었을 때 택시를 타는 것과 같아요.
```

### 1.5 브랜드 원칙 (제품 결정의 기준선)

의사결정이 갈릴 때 이 6개로 판단한다.

1. **사용자는 청소를 좋아해서 앱을 쓰는 게 아니다.** 덜 막막해지려고 쓴다. 재미 요소가 부담을 늘리면 뺀다.
2. **상태와 행동을 일치시킨다.** 정상 항목까지 누르게 만드는 건 가짜 상호작용이다.
3. **직접 하기와 맡기기는 동등하다.** 어느 쪽도 기본값으로 두지 않는다.
4. **광고는 광고라고 말한다.** 제휴 배지를 숨기는 순간 이 브랜드는 끝난다.
5. **실패보다 재시작을 말한다.** 밀린 사용자에게 필요한 건 반성이 아니라 5분짜리 할 일이다.
6. **근거 없는 점수를 만들지 않는다.** "위생 점수 72점"의 72가 무엇인지 설명할 수 없다면 쓰지 않는다. 마지막 완료일과 권장 주기는 설명할 수 있다.

### 1.6 비주얼 방향

| 요소 | 방향 | 이유 |
|---|---|---|
| **컬러 — 상태** | 정상 = 초록 / 임박 = 노랑 / 지연 = 분홍 | 지연에 **빨강을 쓰지 않는다.** 빨강은 경고이고 죄책감이다. 분홍은 "여기 봐줘"에 가깝다 |
| **컬러 — 브랜드** | 물기 빠진 청량한 블루-그린 계열 + 따뜻한 오프화이트 배경 | 소독약 같은 위생 클리셰(형광 파랑, 흰색 일변도)를 피한다 |
| **형태** | 둥근 모서리, 카드 중심, 두꺼운 구분선 없음 | 스탬프의 은유(도장, 스티커북) |
| **아이콘** | 문제 자체를 그린다 (곰팡이, 물때, 배수구). 청소 도구가 아니라 | 사용자는 '해야 할 일'이 아니라 '겪고 있는 것'으로 인식한다 |
| **타이포** | 상태 라벨은 굵게, 문구는 가볍게 | 정보는 단호하게, 말투는 부드럽게 |
| **피해야 할 것** | 반짝임 이펙트, 전후 비교 사진, 벌레 클로즈업 | 공포 마케팅은 단기 전환은 얻고 브랜드를 잃는다 |

### 1.7 게이미피케이션의 경계

뽀득 스탬프는 게임이 아니라 **상태 표시**다.

| 허용 | 금지 |
|---|---|
| 이번 주 스탬프 점수 (완료/전체 기준, 계산식 공개) | 근거 없는 위생 점수, 합성 지표 |
| "이번 주 클리어!" 배지 | 스트릭 끊김 경고, 연속 실패 표시 |
| 완료 시 스탬프가 채워지는 애니메이션 | 타인과의 순위 비교 (초기) |
| 주기 보드에 항목이 쌓이는 시각화 | 방치일수 카운터 ("47일째 방치 중") |

**끄고 켤 수 있어야 한다.** 동기부여 장치가 압박이 되는 순간, 사용자는 앱을 지운다. 이것이 이 카테고리의 1위 이탈 사유다.

## 2. 톤앤매너

### 2.1 톤의 정의

```text
다정하지만 오글거리지 않게
명확하지만 압박하지 않게
초보자도 이해할 수 있게
```

| 축 | 우리 위치 |
|---|---|
| 딱딱함 ←→ 다정함 | **다정함 쪽 70%.** 단, 애교나 유아어는 없다 |
| 압박 ←→ 방임 | **중간.** 사실은 정확히, 요구는 하지 않는다 |
| 전문가 ←→ 친구 | **친구 쪽 60%.** 단 안전 정보에서는 전문가 100% |
| 간결 ←→ 자세함 | **간결.** 현장에서 한 손으로 읽는다 |

### 2.2 문장 규칙

**하는 것**
- 존댓말 기본. "~해요"체 (딱딱한 "~합니다"체는 안전 경고에만)
- 사실을 먼저, 판단은 사용자에게. "권장 주기를 11일 넘겼어요" ○ / "너무 오래 방치했어요" ✕
- 소요 시간을 항상 붙인다. "5분이면", "10분 작업이에요"
- 다음 행동을 문장 안에 넣는다. "~할까요?"로 끝낸다

**하지 않는 것**
- 느낌표 남발 (문장당 최대 1개, 축하 상황에만)
- 이모지 도배 (상태 아이콘 외 문장 내 이모지 금지)
- "드디어", "무려", "충격" 같은 낚시 어휘
- 청결 실패를 인격과 연결하는 표현 ("게으른", "더러운")
- 확정하지 않은 것을 확정처럼 ("최저가 보장" ✕ → "이 판매처가 가장 저렴해요(2026.7.9 기준)" ○)

### 2.3 상황별 문구 가이드

#### 상태 알림

| 상황 | ✕ 피해야 할 톤 | ○ 권장 문구 |
|---|---|---|
| 주기 임박 | "곧 기한입니다" | "이번 주 안에 하면 다음 청소가 쉬워져요" |
| 주기 지연 | "또 밀렸어요" / "기한 초과" | "욕실 곰팡이 점검이 11일 지났어요" |
| 오래 방치 | "심각합니다" | "지금 하면 30분, 더 두면 반나절이 돼요" |
| 여러 개 밀림 | "5개나 밀렸어요" | "오늘은 5분짜리 하나만 골라볼까요?" |
| 재시작 | "다시 시작하세요" | "괜찮아요. 오늘부터 다시 세어볼게요" |

#### 해결 플로우

| 상황 | 문구 |
|---|---|
| 가이드 진입 | "타일 곰팡이, 보통 15분이면 끝나요" |
| 안전 경고 (전문가 톤) | "⚠️ 염소계 세제와 산성 세제를 절대 섞지 마세요. 유독가스가 발생합니다." |
| 소재 주의 | "대리석에는 산성 세제를 쓰면 표면이 상해요" |
| 도구 추천 | "이 문제에는 산성 물때 제거제가 더 잘 맞아요" |
| 대체 방법 제시 | "전용 제품이 없다면 구연산 + 따뜻한 물로도 돼요" |
| 완료 | "해결했어요. 다음 점검은 3~4주 뒤에 알려드릴게요" |

#### 서비스(외주) 제안 — 가장 조심해야 할 구간

| 상황 | 문구 |
|---|---|
| 직접 해결 가능 | "오늘 10분이면 직접 할 수 있어요. 필요한 도구만 확인해볼까요?" |
| 직접 해도 되지만 번거로움 | "직접 해도 되지만 시간이 꽤 걸려요. 이번엔 맡기는 것도 좋은 선택이에요" |
| 전문 장비 필요 | "내부 분해가 필요한 작업이라 전문가에게 맡기는 편이 안전해요" |
| 사용자가 지친 상태 | "청소를 미루고 싶어서가 아니라, 오늘은 쉬는 게 나을 수도 있어요" |
| 반복적으로 밀리는 작업 | "매번 밀리는 작업이라면 정기 서비스로 부담을 줄일 수 있어요" |

> **원칙**: 외주를 권할 때 사용자의 무능을 암시하지 않는다.
> ✕ "직접 하기 어려우시죠?"
> ○ "이건 장비가 있어야 제대로 돼요."

#### 광고·제휴 표기

| 요소 | 문구 |
|---|---|
| 제휴 업체 카드 | 배지: `제휴` — 카드 우상단, 축약 없이 |
| 커머스 링크 | "구매 시 클린루프가 수수료를 받아요" (하단 고정 문구) |
| 스폰서 콘텐츠 | 제목 위에 `광고` 라벨. 편집 콘텐츠와 색상 구분 |
| 가격 표기 | "예상 가격입니다. 지역·일자에 따라 달라질 수 있어요" |

**이건 법적 요구 이전에 브랜드 원칙이다.** 숨기면 한 번 더 클릭되고, 영원히 신뢰를 잃는다.

### 2.4 보송이(캐릭터)의 발화 범위

| 발화한다 | 발화하지 않는다 |
|---|---|
| 상태 알림, 격려, 재시작 유도 | 안전 경고 (시스템/전문가 톤으로) |
| 완료 축하 | 가격·수수료 고지 (중립 톤으로) |
| 온보딩 안내 | 업체 추천 근거 (데이터 톤으로) |

**돈과 안전이 걸린 말은 캐릭터가 하지 않는다.** 귀여운 화자가 결제를 권하면 그건 다크패턴이다.

### 2.5 톤 체크리스트 (문구 작성 시)

- [ ] 사실과 판단이 섞이지 않았는가
- [ ] 사용자를 게으르거나 부족한 사람으로 그리지 않았는가
- [ ] 다음에 뭘 하면 되는지 문장 안에 있는가
- [ ] 소요 시간이나 난이도가 있는가
- [ ] 확정되지 않은 것을 확정처럼 말하지 않았는가
- [ ] 제휴·광고라면 그렇게 적혀 있는가
- [ ] 이 문장을 밀린 지 3주 된 사람이 읽어도 앱을 지우지 않겠는가

마지막 항목이 가장 중요하다.
