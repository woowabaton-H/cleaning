## 2. 제품 정의

클린루프는 오늘 관리할 청소 일을 놓치지 않고, 막히는 청소 문제를 커뮤니티와 선별 추천으로 해결하도록 돕는 청소 생활 앱이다.

MVP는 다음 네 가지 축으로 구성한다.

| 영역 | 역할 |
| --- | --- |
| 주기 관리 | 큰 청소 카테고리 단위로 관리 주기를 확인하고 완료한다 |
| 문제 해결 | 커뮤니티의 꿀팁과 Q&A로 막히는 문제를 해결한다 |
| 선별 추천 | 청소 용품과 서비스를 브랜드 관점으로 선별해 소개한다 |
| 기록 | 완료한 청소와 저장한 추천을 다시 확인한다 |

## 3. 우선순위

| 우선순위 | 의미 |
| --- | --- |
| P0 | MVP 필수. 최종 기획서와 프로토타입의 핵심 루프를 구현하는 데 필요 |
| P1 | MVP 권장. 초기 제품 완성도와 신뢰도를 높이는 기능 |
| P2 | 추후 확장. 최종 기획서의 확장 방향에 해당 |

## 4. 사용자

| 사용자 | 주요 니즈 |
| --- | --- |
| 자취 초기 사용자 | 기본적인 청소 주기와 시작점이 필요하다 |
| 바쁜 직장인 | 오늘 또는 이번 주에 챙길 일을 가볍게 정리하고 싶다 |
| 청소 초보 사용자 | 신뢰할 수 있는 팁과 선별된 추천이 필요하다 |
| 외부 서비스를 가끔 쓰는 사용자 | 상황에 맞는 서비스 후보와 판단 기준을 보고 싶다 |

## 5. 전체 사용자 흐름

```text
앱 진입
-> 오늘/이번 주 관리할 청소 카테고리 확인
-> 완료 또는 주기 조정
-> 막히는 문제 발생 시 커뮤니티 또는 셀렉션 확인
-> 도움 되는 글이나 추천 저장
-> 완료 기록과 저장 항목 확인
-> 다음 관리 시점에 다시 방문
```

## 17. MVP 수용 기준

1. 사용자는 앱을 열고 오늘 또는 이번 주에 챙기면 좋은 청소 카테고리를 확인할 수 있다.
2. 사용자는 카테고리를 완료하고, 완료 기록과 다음 관리일 갱신을 즉시 확인할 수 있다.
3. 사용자는 카테고리 주기를 3일, 7일, 14일, 21일, 28일 중 하나로 수정할 수 있다.
4. 사용자는 새 카테고리 추가 시나리오를 수행할 수 있다.
5. 사용자는 카테고리에서 도움 보기를 선택해 관련 셀렉션으로 이동할 수 있다.
6. 사용자는 셀렉션 목록을 카테고리별로 필터링하고, 상세를 보고, 저장할 수 있다.
7. 셀렉션은 추천 이유, 적합한 상황, 가격대, 제휴 여부, 외부 보기 CTA를 제공한다.
8. 사용자는 커뮤니티에서 꿀팁과 Q&A를 구분해 보고, 글 상세를 확인하고, 도움됨을 표시할 수 있다.
9. 사용자는 마이에서 이번 달 완료 수, 관리 카테고리 수, 저장 셀렉션 수, 최근 완료 기록, 저장한 셀렉션을 확인할 수 있다.
10. 알림은 이번 주에 챙기면 좋은 항목을 제안하고, 주기 보기 또는 완료로 이어져야 한다.
