# 원본 산출물 인사이트 요약

작성일: 2026-07-10  
대상 폴더: `huchu`, `if`, `몽이`, `테리`

## 1. 검토 목적

네 사람의 산출물에서 청소 생활 앱으로 발전시킬 수 있는 문제 정의, 사용자 관점, 서비스 흐름, 운영 관점을 추출했다. 이 문서는 최종 기획서의 배경 자료이며, 원본별 장점을 제품 방향으로 정리하는 데 목적이 있다.

## 2. 원본별 주요 인사이트

### huchu

huchu의 산출물은 청소 생활 앱의 기본 구조가 가장 명확했다. 청소 주기 관리, 커뮤니티, 청소템 탐색이 각각 다른 역할을 가지면서도 사용자가 막히는 순간에는 서로 이어질 수 있도록 설계되어 있었다.

특히 좋은 점은 청소를 단순 체크리스트로 보지 않고, 사용자의 생활 리듬 안에서 반복되는 관리 문제로 본 것이다. 사용자가 오늘 무엇을 해야 하는지 확인하고, 필요한 정보를 찾고, 다시 완료 기록으로 돌아오는 흐름이 최종 기획의 기본 골격이 되었다.

### if

if의 산출물은 청소 문제를 `판단과 실행의 문제`로 본 관점이 강했다. 사용자는 청소를 해야 한다는 사실보다 무엇을 써야 하는지, 직접 할지 맡길지, 다음에는 어떻게 관리할지에서 더 자주 막힌다.

또한 추천과 서비스 연결을 다룰 때 신뢰가 중요하다는 점을 잘 짚었다. 상품이나 서비스가 광고처럼 보이지 않으려면 추천 이유, 가격 기준, 제휴 여부가 함께 설명되어야 한다. 이 관점은 브랜드 셀렉션의 운영 원칙에 반영했다.

### 몽이

몽이의 산출물은 사용자가 앱을 다시 열 이유를 만드는 데 강점이 있었다. 홈에서 청소 주기를 확인하고, 완료하고, 기록을 쌓는 흐름이 자연스러웠다. 청소를 무거운 숙제가 아니라 생활 속에서 다시 챙길 수 있는 루프로 표현한 점도 좋았다.

최종 기획에서는 이 장점을 살려 홈을 반복 사용의 중심으로 두고, 완료 기록이 사용자의 관리 감각을 만들어주는 구조로 정리했다.

### 테리

테리의 산출물은 브랜드와 운영 신뢰에 대한 기준이 구체적이었다. 청소 용품과 서비스는 추천의 이유가 분명해야 하고, 안전 정보나 제휴 여부를 투명하게 다뤄야 한다는 관점이 강했다.

이 관점은 셀렉션과 커뮤니티 운영 원칙에 반영했다. 사용자가 추천을 신뢰하려면 무엇을 소개하는지보다 왜 소개하는지가 먼저 보여야 한다.

## 3. 공통으로 확인한 방향

네 산출물에서 반복적으로 확인한 방향은 다음과 같다.

1. 청소 앱의 핵심은 사용자가 관리 리듬을 놓치지 않게 돕는 것이다.
2. 첫 사용은 가벼워야 한다.
3. 완료 기록은 반복 사용의 중요한 근거가 된다.
4. 청소 정보, 용품, 서비스는 흩어져 있어 사용자가 판단하기 어렵다.
5. 추천은 신뢰할 수 있어야 하며, 추천 근거가 함께 필요하다.
6. 커뮤니티는 막히는 문제를 해결하는 데 도움이 될 때 가치가 커진다.

## 4. 최종 기획에 반영한 강점

| 반영 요소 | 참고 원본 | 적용 방향 |
| --- | --- | --- |
| 청소 주기 관리 | huchu, 몽이, 테리 | 큰 청소 카테고리를 중심으로 관리 리듬을 만든다 |
| 완료 기록 | huchu, if, 몽이 | 사용자가 청소를 마친 순간을 쉽게 기록하게 한다 |
| 홈 중심 반복 사용 | 몽이 | 앱을 열었을 때 바로 오늘 챙길 일을 확인한다 |
| 문제 해결 관점 | if, 테리 | 방법, 용품, 서비스 선택을 사용자의 막힘 해결과 연결한다 |
| 브랜드 셀렉션 | if, 테리 | 추천 이유와 맞는 상황을 중심으로 소개한다 |
| 커뮤니티 | huchu, 테리 | 실제 경험과 질문 답변이 쌓이는 공간으로 둔다 |
| 브랜드 신뢰 | 테리 | 안전, 제휴, 가격 변동성을 투명하게 다룬다 |

## 5. 최종 방향

최종안은 청소 생활의 반복 리듬을 만드는 데 집중한다. 사용자는 큰 청소 카테고리를 기준으로 오늘 챙길 일을 확인하고, 완료하고, 필요할 때 커뮤니티와 셀렉션에서 도움을 얻는다.

제품의 중심은 구매나 예약이 아니라 관리의 지속성이다. 용품과 서비스는 사용자가 막히는 순간 참고할 수 있는 좋은 선택지로 다루고, 커뮤니티는 실제 경험과 질문 답변이 쌓이는 문제 해결 공간으로 운영한다.
