# 클린루프 최종 통합 기획서

작성일: 2026-07-09  
서비스명: 클린루프(CleanLoop)  
문서 목적: 네 원본 산출물을 통합해 실제 MVP 기획, 디자인, 프로토타입 개발에 바로 사용할 수 있는 최종안을 정의한다.

## 1. 서비스 한 줄 정의

클린루프는 집안 청소 상태를 보여주고, 필요한 순간 청소 방법, 준비물, 전문가 예약까지 이어주며, 해결 후 다음 관리 주기를 자동으로 잡아주는 생활 위생 관리 서비스다.

```text
상태가 알려주고, 해결까지 이어준다.
```

## 2. 배경 및 문제 정의

청소는 단순한 할 일 목록이 아니다. 침구 세탁, 배수구 냄새, 욕실 물때, 주방 기름때, 세탁조 냄새, 쓰레기 배출처럼 항목마다 주기와 난이도, 필요한 도구, 맡길 수 있는 서비스가 다르다. 사용자는 청소를 해야 한다는 사실을 알아도 무엇부터 해야 하는지, 직접 해결 가능한지, 어떤 도구가 필요한지, 언제 전문가에게 맡겨야 하는지 매번 새로 판단해야 한다.

기존 청소 트래커는 마지막 완료일과 반복 주기를 보여주지만 해결 수단이 약하다. 청소 업체 앱은 서비스를 제공하지만 사용자가 먼저 문제를 인식하고 찾아와야 한다. 커머스는 상품을 잘 팔지만 문제 맥락 없이 제품을 나열한다. 검색과 커뮤니티는 정보가 많지만 신뢰, 안전, 실행 연결이 약하다.

클린루프의 문제 정의는 다음 세 가지다.

| 문제 | 설명 | 제품 기회 |
| --- | --- | --- |
| 상태가 보이지 않으면 청소는 밀린다 | 주기가 서로 다른 집안일을 머릿속으로 기억하기 어렵다 | 기본 주기와 색상 상태로 오늘 볼 일을 보여준다 |
| 방법과 실행 수단이 흩어져 있다 | 검색, 쇼핑, 업체 비교, 기록 관리가 분리되어 있다 | 가이드, 청소템, 전문가 연결을 한 흐름에 둔다 |
| 외주는 큰 결심처럼 느껴진다 | 4시간 단위 청소와 큰 결제는 1인 가구에게 부담이다 | 문제 단위, 부분 청소, 수거/세탁 같은 작은 외주를 먼저 연결한다 |

## 3. 타깃 사용자

### 3.1 1차 타깃

| 타깃 | 상황 | 핵심 니즈 |
| --- | --- | --- |
| 자취 1~3년차 1인 가구 | 청소 기준과 도구 지식이 부족하다 | 기본 주기, 쉬운 가이드, 필요한 도구 추천 |
| 바쁜 직장인 | 평일에 미루고 주말에 몰아서 처리하려다 포기한다 | 오늘 가장 중요한 항목과 짧은 해결 경로 |
| 청소 방치 경험자 | 곰팡이, 냄새, 벌레 등으로 한 번 고생한 경험이 있다 | 재발 방지, 다음 주기 자동 관리 |
| 외주 가능성이 있는 사용자 | 세탁/수거/청소 앱은 알지만 언제 써야 할지 모른다 | 문제 상황에 맞는 서비스와 예상 가격 비교 |

### 3.2 확장 타깃

| 타깃 | 확장 이유 | 필요한 기능 |
| --- | --- | --- |
| 룸메이트, 커플, 가족 | 담당자와 완료 기록이 갈등을 줄인다 | 구성원 초대, 담당자, 완료 기록 공유 |
| 반려동물/아이 가구 | 털, 냄새, 소독, 안전한 세제 니즈가 크다 | 생활 조건별 주기 보정, 안전 콘텐츠 |
| 개인 숙박 운영자 | 청결이 리뷰와 매출에 직접 연결된다 | 다중 공간 보드, 업체 호출, 완료 사진 |
| 원룸/오피스텔 관리자 | 입퇴거 청소와 민원 관리가 반복된다 | 여러 호실 관리, 파트너 이력, B2B 리포트 |

## 4. 사용자 페르소나

### 김보송, 26세, 직장인 2년차, 자취 3년차

- 평일 야근이 잦고 배달음식 비중이 높다.
- 주말에 청소하려고 해도 세제나 도구가 없어 흐름이 끊긴다.
- 작년 여름 욕실 곰팡이를 방치해 주말 하루를 통째로 쓴 경험이 있다.
- 세탁 수거와 가사청소 서비스는 알지만 언제 무엇을 맡겨야 할지 몰라 잘 쓰지 않는다.
- 원하는 것은 완벽한 집안일 관리가 아니라, 지금 하나만 해결할 수 있는 명확한 다음 행동이다.

### 이하우, 30세, 커플 동거 중

- 집안일 분담을 정했지만 누가 언제 했는지 기록이 남지 않는다.
- 한 사람이 계속 기억하고 말하게 되면 잔소리처럼 들린다.
- 담당자와 완료 기록이 보이면 대화가 줄고 역할이 명확해질 것이라고 느낀다.

### 박스테이, 32세, 개인 숙박 운영자

- 객실 청결이 리뷰와 예약률에 직접 영향을 준다.
- 세탁, 쓰레기, 욕실, 바닥, 에어컨 청소를 각각 따로 관리하는 데 피로가 있다.
- 장기적으로 여러 공간의 주기와 업체 호출을 한 보드에서 관리하고 싶다.

| 판단 비용 절감 | 직접 할지 맡길지 고를 수 있다 | 빠른 해결 시트, 전문가 기준선, 업체 비교 |

## 6. 서비스 범위

### 6.1 MVP 포함

| 영역 | 기능 |
| --- | --- |
| 홈 | 오늘의 청소 상태, 주간 클리어, 지연/임박 카드, 예약 상태, 빠른 해결 |
| 해결/예약 | 문제 선택, 가이드, 청소템 보기, 전문가 예약 견적, 매칭, 예약 확인 |
| 주기 | 기본 추천 주기, 전체 작업 리스트, 상태 필터, 완료, 미루기, 담당자 표시 |
| 커뮤니티 | 관리자 가이드, Q&A, 잡담/생활 이야기, 저장/도움됨, 관리자 가이드의 실행 연결 |
| 청소템 | 문제별 준비물, 상품 가격 예시, 후기 요약, 판매처 링크, 제휴 표시 |
| 마이 | 청소발자국, 완료 히스토리, 구성원 요약, 담당 현황, 찜한 청소템 |
| 운영 데이터 | 기본 6개 카테고리, 우선 이슈, 업체/용품 정적 데이터, 가격 확인 시점 |

### 6.2 MVP 제외

- 자체 결제, 장바구니, 배송, 환불.
- 업체 실시간 예약 API.
- 사진 기반 AI 진단.
- 자체 청소 인력 운영.
- 자체 크레딧 구독.
- 고도화된 관리자 도구.
- 완전한 커뮤니티 모더레이션 자동화.
- B2B 다중 공간 관리.

## 7. 주요 기능 목록

### 7.1 주기 대시보드

- 기본 6개 카테고리: 침구·빨래, 욕실·곰팡이, 주방, 쓰레기·수거, 해충·방역, 바닥·공간.
- 상태: 정상, 임박, 지연, 예약됨.
- 각 카드 표시 정보: 작업명, 공간/문제군, 담당자, 마지막 완료일, 다음 권장일, 상태, 추천 행동.
- 액션: 방법 보기, 예약 견적, 완료, 미루기.
- 완료 시 `ResolutionLog` 생성 후 다음 권장일 갱신.

### 7.2 빠른 해결 시트

- 세부 이슈 선택.
- 원인, 난이도, 예상 소요 시간.
- 준비물과 대체 방법.
- 단계별 방법.
- 안전 주의.
- 직접 완료, 청소템 보기, 전문가 예약.

### 7.3 예약 견적/매칭

- 서비스 선택: 욕실 집중 청소, 쓰레기 정기 수거, 침구/세탁 수거, 주방 부분 청소, 가전/에어컨 케어.
- 공간 정보: 거주 형태, 평수/면적, 오염도, 특이사항.
- 일정 선택: 날짜, 시간대.
- 견적 확인: 예상 가격, 추가 비용 조건, 소요 시간.
- 전문가/업체 매칭: 가능 지역, 평점, 후기 수, 제공 범위, 제외 범위, 보험/보상, 제휴 여부.
- 예약 확인: 사용자가 선택한 업체와 일정, 예상 가격, 주기 갱신 안내.
- MVP에서는 외부 예약/문의 연결 또는 리드 생성으로 처리한다.

### 7.4 커뮤니티

- 관리자 가이드: 검수된 문제 해결 콘텐츠. 관련 청소템과 서비스 연결 가능.
- Q&A: 사용자가 사진과 태그로 질문하고 답변을 받는 영역. 상품/서비스 연결을 기본으로 강제하지 않는다.
- 잡담/생활 이야기: 집안일 경험, 팁, 생활 이야기. 광고성 연결을 제한한다.
- 경험 공유: 사용한 청소템/서비스, 해결 전후 경험, 만족도.

### 7.5 청소템

- 문제별 준비물 묶음.
- 상품 정보: 브랜드, 상품명, 가격 예시, 할인율, 평점, 후기 수, 핵심 용도.
- 판매처 정보: 판매처명, 가격, 배송 조건, 가격 확인 시점, 외부 링크.
- 추천 근거와 제휴 여부를 명확히 표시.
- 대체 방법과 이미 보유한 도구를 우선 안내해 신뢰를 유지한다.

### 7.6 마이페이지

- 청소발자국: 최근 완료 기록과 월간 완료 수.
- 완료 히스토리: SELF, COMMERCE, PARTNER, SUBSCRIPTION 구분.
- 공동 가구: 구성원, 담당 작업, 초대 진입점.
- 담당 현황: 구성원별 담당 중인 주기.
- 이번 주 요약: 완료 수, 지연 해결 수, 예약됨 수.
- 내 활동: 저장한 가이드, 내가 쓴 질문/답변, 찜한 청소템.

## 8. 사용자 시나리오

### 시나리오 A: 지연된 욕실 곰팡이를 직접 해결

1. 사용자가 홈에서 `욕실 줄눈 곰팡이` 지연 카드를 본다.
2. `방법`을 눌러 빠른 해결 시트를 연다.
3. 타일 줄눈 곰팡이 이슈를 선택한다.
4. 15분 예상 가이드, 준비물, 혼합 금지 주의사항을 확인한다.
5. 이미 도구가 있으면 `직접 해결 완료`를 누른다.
6. 완료 로그가 쌓이고 다음 점검일이 자동 등록된다.
7. 홈과 주기 보드에서 해당 항목이 정상으로 바뀐다.

### 시나리오 B: 쓰레기 수거를 외주로 예약

1. 알림 또는 홈 카드에서 `쓰레기·수거` 지연 상태를 확인한다.
2. `예약 견적`을 누른다.
3. 서비스로 `문앞 정기 수거`를 선택한다.
4. 거주 형태, 평수, 배출 빈도, 희망 요일을 선택한다.
5. 오늘수거, 커버링, 로컬 수거팀 카드에서 가격, 후기, 가능 지역, 제휴 여부를 비교한다.
6. 업체를 선택하고 예약을 확인한다.
7. 상태가 `예약됨`으로 전환되고 다음 주기가 예약 기준으로 갱신된다.

### 시나리오 C: 커뮤니티 가이드에서 청소템과 서비스로 연결

1. 커뮤니티에서 `샤워부스 물때 제거` 관리자 가이드를 연다.
2. 소재별 주의사항과 단계별 방법을 확인한다.
3. 필요한 물때 제거제와 부드러운 솔을 청소템 카드로 확인한다.
4. 직접 하기 번거로우면 욕실 집중 청소 예약 견적으로 이동한다.
5. 가이드를 저장하고 나중에 마이페이지에서 다시 본다.

### 시나리오 D: 공동 가구에서 담당자 기록 확인

1. 마이페이지의 공동 가구에서 구성원과 담당 항목을 본다.
2. 주기 보드에서 `침구 세탁` 담당자를 변경한다.
3. 담당자가 완료하면 완료 로그에 담당자와 방식이 남는다.
4. 이번 주 요약에서 함께 완료한 작업 수를 확인한다.

## 9. 전체 사용자 플로우

```text
온보딩
  -> 기본 카테고리와 추천 주기 확인
  -> 함께 사는 사람 여부 선택
  -> 홈 대시보드 진입

상태 기반 해결
  -> 지연/임박 카드 확인
  -> 빠른 해결 시트
  -> 가이드 확인
  -> 직접 완료 또는 청소템 보기 또는 예약 견적
  -> 완료/예약 로그 생성
  -> 다음 권장일 갱신

예약 견적
  -> 서비스 선택
  -> 공간/평수/오염도 입력
  -> 일정 선택
  -> 견적/업체 비교
  -> 예약 확인
  -> 예약됨 상태와 히스토리 반영

정보 탐색
  -> 커뮤니티
  -> 관리자 가이드, Q&A, 잡담 중 선택
  -> 저장/답변/도움됨
  -> 관리자 가이드에서만 청소템/서비스 연결

기록 확인
  -> 마이페이지
  -> 청소발자국, 완료 히스토리, 구성원, 찜한 청소템 확인
```

## 10. 화면 구성안

### 홈

- 상단: 이번 주 상태 문장, 주간 클리어 진행도.
- 상태 스탬프: 6개 카테고리의 정상/임박/지연/예약 상태.
- 지금 확인할 항목: 지연과 예약 필요 항목 우선 노출.
- 예약됨 요약: 예약한 업체, 일정, 상태.
- 빠른 청소: 5~10분 작업.

### 해결/예약

- 카테고리 선택.
- 문제 선택.
- 가이드.
- 청소템/서비스 비교.
- 예약 견적 플로우.

### 주기

- 필터: 전체, 욕실, 주방, 침구, 수거, 기타.
- 주기 카드: 마지막 완료일, 다음 권장일, 담당자, 상태.
- 완료, 미루기, 수정.

### 커뮤니티

- 탭/세그먼트: 관리자 가이드, Q&A, 잡담.
- 카드 정보: 제목, 공간, 예상 소요 시간, 답변/댓글 수, 저장 여부.
- 관리자 가이드 상세: 원인, 준비물, 단계, 안전 주의, 관련 청소템/서비스.

### 마이

- 프로필/가구 요약.
- 청소발자국과 히스토리.
- 구성원과 담당 현황.
- 저장한 가이드, 찜한 청소템.
- 알림/주기 설정.

## 11. MVP 범위

### 11.1 반드시 구현

1. 기본 6개 카테고리와 주기 상태.
2. 홈 대시보드와 주간 클리어.
3. 지연 카드에서 시작하는 빠른 해결 시트.
4. 가이드, 청소템, 서비스 예약 CTA.
5. 예약 견적: 서비스, 공간/평수, 일정, 견적, 업체 선택, 예약 확인.
6. 주기 보드의 완료와 미루기.
7. 커뮤니티 3분류와 관리자 가이드 실행 연결.
8. 마이페이지 청소발자국과 완료 방식 구분.
9. 제휴/가격/외부 이동 고지.
10. 모바일 기준 반응형 프로토타입.

### 11.2 검증 기준

- 첫 화면에서 사용자가 무엇이 밀렸는지 5초 안에 이해한다.
- 지연 카드에서 4단계 이내로 직접 완료 또는 예약 확인에 도달한다.
- 예약 견적에서 가격, 제공 범위, 제외 범위, 제휴 여부가 보인다.
- 완료/예약 후 홈, 주기, 마이 히스토리가 갱신된다.
- 커뮤니티 Q&A와 잡담에는 상품/서비스 연결이 과도하게 붙지 않는다.
- 모든 안전 경고는 캐릭터 톤이 아니라 시스템 톤으로 표시한다.

## 12. 추후 확장 범위

| 단계 | 확장 |
| --- | --- |
| 0~3개월 | 알림 설정, 계절 카테고리, 검색, 더 많은 관리자 가이드, 지역별 파트너 데이터 갱신 |
| 3~9개월 | 공동 가구 초대, 담당자 로테이션, 보유 도구 등록, 개인화 주기 보정, 후기 작성 |
| 9개월 이후 | B2B 다중 공간 관리, 사진 기반 상태 진단, 업체 대시보드, 결제/정산 자동화, PB 청소 키트 |

## 13. 운영 정책 및 고려사항

### 13.1 콘텐츠 운영

- 모든 관리자 가이드는 전문가 검수 또는 신뢰 가능한 출처 기반으로 작성한다.
- 사용자 Q&A와 관리자 가이드는 시각적으로 구분한다.
- 안전 주의는 본문 하단이 아니라 가이드 상단에 고정 노출한다.
- 가이드 구조는 `먼저 확인할 것, 준비물, 단계, 잘 안 될 때, 하면 안 되는 것, 재발 방지, 완료`로 통일한다.

### 13.2 청소템 운영

- 직접 판매가 아니라 외부 판매처 연결로 시작한다.
- 가격은 `예상`, `확인 시점`, `판매처`를 함께 표시한다.
- 실시간 최저가 보장 표현을 쓰지 않는다.
- 제휴 상품은 배지와 하단 안내문으로 명확히 표시한다.
- 대체 방법을 함께 제공해 추천 신뢰를 유지한다.

### 13.3 업체 운영

- 업체 카드 필수 정보: 가능 지역, 가격과 추가 비용 조건, 가능한 날짜/시간, 평균 소요 시간, 제공 범위, 제외 범위, 후기/별점, 취소 정책, 보험/보상, 제휴 여부.
- 초기 제휴 우선순위: 쓰레기 수거, 커머스 제휴, 세탁 수거, 부분 가사청소, 에어컨/전문 청소, 방역/대형폐기물.
- 예약/결제는 MVP에서 외부 업체로 연결하며, 클린루프는 통신판매중개자 역할을 명확히 고지한다.
- 반복 클레임, 낮은 만족도, 가격 불투명 업체는 노출을 제한한다.

### 13.4 알림 정책

- 기본 알림은 주 1회 이하.
- 지연을 실패처럼 말하지 않는다.
- 반복 미루기 3회째에는 주기 조정 또는 정기 서비스 제안을 한다.
- 30일 이상 미접속 후 복귀하면 모든 지연 항목을 나열하지 않고 하나만 제안한다.

## 14. 청소 서비스 도메인 특화 고려사항

| 항목 | 고려사항 |
| --- | --- |
| 세제 안전 | 염소계와 산성 세제 혼합 금지, 환기, 장갑/마스크, 소재별 금지 세제를 필수 안내 |
| 전문가 기준선 | 에어컨 송풍팬/열교환기, 배관 역류, 깊은 줄눈 곰팡이, 매트리스 내부 살균 등은 전문가 권장 |
| 가격 변동 | 지역, 일자, 평수, 오염도, 성수기, 층고, 분해 범위에 따라 가격이 달라진다 |
| 부분 청소 | 1인 가구에는 집 전체 청소보다 욕실, 주방, 수거, 침구 같은 작은 단위가 적합하다 |
| 계절성 | 장마철 곰팡이, 여름 쓰레기/해충, 봄 에어컨, 겨울 결로는 노출 주기와 카피를 조정해야 한다 |
| 공동 생활 | 담당자 기능은 감시가 아니라 역할 가시화를 목적으로 해야 한다 |

## 15. 차별화 포인트

1. 주기 관리에서 끝나지 않고 해결 방법, 도구, 전문가 연결까지 이어진다.
2. 검색/쇼핑/업체 예약으로 흩어진 실행 경로를 문제 단위로 묶는다.
3. `여기부터는 전문가` 기준선으로 사용자가 무리한 직접 해결과 불필요한 외주를 구분하게 한다.
4. 커뮤니티의 관리자 콘텐츠와 사용자 글을 분리해 정보 신뢰를 유지한다.
5. 완료 기록이 다음 주기를 자동으로 만든다.
6. 제휴와 가격 정보를 숨기지 않는 투명한 중개 모델을 지향한다.
7. 청소를 못했다는 죄책감보다 다시 시작할 수 있는 상태 UX를 설계한다.

## 16. 성공 지표

### 16.1 North Star Metric

월간 해결된 청소 문제 수

해결 방식은 다음으로 분리해 추적한다.

- SELF: 직접 해결.
- COMMERCE: 청소템 확인 또는 외부 구매 이동 후 해결.
- PARTNER: 업체 문의/예약 후 해결.
- SUBSCRIPTION: 파트너 정기 서비스 연결 후 해결.

### 16.2 핵심 지표

| 단계 | 지표 | 의미 |
| --- | --- | --- |
| 유입 | 홈 진입 후 지연 카드 클릭률 | 상태 표시가 행동을 만드는가 |
| 활성화 | 첫 주기 완료율 | 앱이 첫 행동까지 이끄는가 |
| 해결 | 가이드 조회 후 완료율 | 정보가 실제 해결로 이어지는가 |
| 예약 | 예약 견적 시작률, 업체 카드 클릭률, 예약 확인률 | 외주 수요가 있는가 |
| 커머스 | 청소템 상세 조회율, 외부 판매처 이동률 | 문제 기반 도구 추천이 유효한가 |
| 커뮤니티 | 관리자 가이드 저장/도움됨, Q&A 작성률 | 정보 탐색 공간으로 작동하는가 |
| 리텐션 | 주간 클리어 달성률, D7/D30 재방문율 | 주기 루프가 재방문을 만드는가 |
| 공동 사용 | 초대된 가구의 주간 활성 구성원 수 | 역할 공유 가치가 있는가 |
| 품질 | 업체 만족도, 클레임률, 가격 정보 오류율 | 중개 신뢰가 유지되는가 |

## 18. 최종 의사결정 요약

- 서비스명은 `클린루프`로 통일한다.
- `보송이`는 캐릭터/화자 이름으로만 사용한다.
- MVP의 핵심은 주기 관리가 아니라 `해결된 청소 문제 수`를 늘리는 것이다.
- 커뮤니티는 포함하되 관리자 가이드 중심으로 가볍게 시작한다.
- 청소템은 직접 판매가 아니라 문제 해결용 탐색과 외부 판매처 연결이다.
- 예약은 자체 결제가 아니라 견적/매칭/외부 연결로 시작한다.
- 신뢰를 잃을 수 있는 숨은 제휴, 공포 마케팅, 근거 없는 위생 점수는 쓰지 않는다.
