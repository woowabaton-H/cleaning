# 청소 생활 앱 최종 기획서

작성일: 2026-07-10  
서비스명: 미정. 본 문서에서는 가칭 `클린루프`로 표기한다.  
문서 목적: MVP에서 검증할 문제, 해결 방식, 화면 구조, 프로토타입 기준을 명확히 정의한다.

## 1. 서비스 한 줄 정의

오늘 관리할 일은 놓치지 않고, 막히는 청소 문제는 함께 해결하는 청소 생활 앱

## 2. 우리가 풀 문제

청소가 어려운 이유는 사용자가 청소를 싫어해서가 아니다. 대부분은 언제 해야 하는지 놓치고, 막상 하려는 순간 무엇부터 해야 할지 몰라 멈춘다. 검색을 열면 정보는 많지만 내 상황에 맞는 답을 고르기 어렵고, 쇼핑몰은 상품을 팔지만 어떤 용품이 왜 필요한지는 충분히 설명하지 않는다. 서비스 예약 앱은 청소를 맡기는 데는 좋지만, 평소에 언제 맡겨야 할지는 알려주지 않는다.

MVP에서 가장 먼저 해결할 문제는 명확하다.

| 문제 | 사용자에게 생기는 일 | MVP의 해결 |
| --- | --- | --- |
| 청소 주기를 기억하기 어렵다 | 욕실, 주방, 세탁, 수거처럼 주기가 다른 일을 머릿속으로 관리하다가 놓친다 | 큰 카테고리별 추천 주기를 기본 제공하고, 홈에서 바로 완료/수정하게 한다 |
| 시작 전에 세팅이 많으면 앱을 지운다 | 방, 세부 작업, 반복 규칙을 모두 입력하다가 포기한다 | 세부 항목 등록 없이 큰 카테고리만으로 시작한다 |
| 막혔을 때 검색과 쇼핑이 흩어진다 | 어떤 방법이 맞는지, 어떤 용품이나 서비스가 괜찮은지 따로 판단해야 한다 | 브랜드가 고른 청소 용품과 서비스, 커뮤니티 꿀팁/Q&A를 연결한다 |
| 추천이 광고처럼 보이면 신뢰가 깨진다 | 상품이나 서비스가 필요한 정보가 아니라 판매처럼 느껴진다 | 편집숍처럼 추천 이유, 사용 맥락, 제휴 여부를 투명하게 보여준다 |

핵심은 `청소를 더 많이 하게 만드는 것`이 아니라 `관리할 일을 놓치지 않고, 막히는 순간에 다음 선택지를 쉽게 찾게 하는 것`이다.

## 3. 타깃 사용자

### 3.1 1차 타깃

| 타깃 | 상황 | 필요한 가치 |
| --- | --- | --- |
| 자취 1~3년차 1인 가구 | 집 관리 기준이 아직 없다 | 욕실, 주방, 세탁, 수거 등 기본 주기 기준 |
| 바쁜 직장인 | 평일에 미루고 주말에 몰아서 하려다 놓친다 | 홈에서 오늘/이번 주 관리할 카테고리를 바로 확인 |
| 청소 초보 사용자 | 방법, 용품, 주의사항을 잘 모른다 | 꿀팁 공유, Q&A, 브랜드 셀렉션 |
| 외주를 가끔 쓰는 사용자 | 세탁/수거/청소 서비스를 알지만 매번 비교하기 귀찮다 | 상황별로 믿을 만한 서비스 후보를 모아보는 경험 |

### 3.2 MVP에서 제외하는 타깃

개인 숙박 운영자, 원룸/오피스텔 관리자, 소규모 오피스 관리자는 이번 MVP의 주 사용자가 아니다. 이들은 여러 공간, 담당자, 업체 이력, 비용 정산이 필요해 개인용 청소 생활 앱과 요구사항이 크게 다르다. B2B는 개인 사용자 MVP가 검증된 뒤 별도 제품 방향으로 검토한다.

공동 가구 기능도 이번 MVP에서 제외한다. 담당자 배정, 구성원 초대, 공유 기록은 좋은 확장 기능이지만 초기 핵심 문제인 개인의 청소 주기 관리와 막힘 해결을 흐릴 수 있다.

## 4. 페르소나

### 김보송, 26세, 직장인 2년차, 자취 3년차

- 평일에는 늦게 들어와 집안일을 미룬다.
- 욕실, 세탁, 분리수거처럼 해야 할 일이 있다는 건 알지만 정확히 언제 했는지 기억하지 못한다.
- 청소 앱을 깔아본 적은 있지만 세부 항목을 등록하다가 그만뒀다.
- 검색으로 방법을 찾으면 광고성 글이 많아 무엇을 믿어야 할지 모르겠다.
- 원하는 것은 모든 청소를 완벽하게 관리하는 앱이 아니라, 이번 주에 챙길 큰 카테고리를 놓치지 않게 해주는 앱이다.

### 박루틴, 24세, 자취를 막 시작한 사용자

- 욕실, 주방, 침구, 쓰레기를 얼마나 자주 관리해야 하는지 기준이 없다.
- 청소 도구를 한꺼번에 사려니 무엇이 기본인지 모르겠다.
- 다른 사람들이 실제로 쓰는 팁이나 질문 답변을 보고 싶다.
- 브랜드가 초보자에게 필요한 최소 용품과 서비스를 골라주면 참고할 의향이 있다.

## 5. 제품 원칙

1. **MVP의 중심은 청소 주기다.** 사용자가 홈에서 큰 카테고리별 주기를 보고 완료할 수 있어야 한다.
2. **세부 청소 항목은 MVP 주기 관리 대상이 아니다.** 욕실 줄눈, 배수구, 후드처럼 세세한 항목은 커뮤니티나 셀렉션의 문제 해결 맥락에서 다룬다.
3. **지연 카드로 압박하지 않는다.** 지연/연체를 강조하는 카드 대신, 오늘 또는 이번 주에 관리하면 좋은 카테고리를 부드럽게 보여준다.
4. **용품과 서비스는 브랜드 셀렉션이다.** 쇼핑몰처럼 나열하지 않고, 우리가 고른 이유와 사용 상황을 설명한다.
5. **커뮤니티는 관리자 가이드가 아니라 사용자 중심이다.** 꿀팁 공유와 Q&A를 중심으로 운영하고, 반응이 좋은 글을 상단에 강조한다.
6. **서비스명은 임시다.** 현재 문서와 프로토타입에서는 가칭을 쓰되, 브랜드명이 확정되면 네이밍과 문구를 교체할 수 있게 둔다.

## 6. 핵심 가치 제안

| 가치 | 설명 | 화면/기능 |
| --- | --- | --- |
| 주기 기준 제공 | 사용자가 처음부터 청소 주기를 설계하지 않아도 된다 | 기본 카테고리와 추천 주기 |
| 완료의 쉬움 | 카테고리 단위로 오늘 했음을 빠르게 기록한다 | 홈 카테고리 카드의 완료 버튼 |
| 막힘 해결 | 청소 방법이 막히면 커뮤니티와 셀렉션에서 도움을 찾는다 | 꿀팁 공유, Q&A, 셀렉션 |
| 선별된 추천 | 좋은 청소 용품과 서비스를 브랜드 관점으로 소개한다 | `셀렉션` 탭의 에디터 추천 카드 |
| 부담 없는 재시작 | 못 했다는 죄책감보다 다시 관리할 수 있는 상태를 만든다 | 지연 표현 최소화, 부드러운 알림 |

## 7. MVP 범위

### 7.1 포함 기능

| 영역 | 기능 |
| --- | --- |
| 홈/주기 | 큰 카테고리별 주기 카드, 마지막 완료일, 다음 관리일, 완료, 주기 수정, 카테고리 추가 |
| 셀렉션 | 브랜드가 고른 청소 용품, 기본 키트, 서비스 후보, 추천 이유, 제휴 표시 |
| 커뮤니티 | 꿀팁 공유, Q&A, 반응 많은 꿀팁/질문 상단 강조, 글 상세 보기 |
| 마이 | 청소 기록, 월간 완료 수, 저장한 셀렉션, 내가 본 질문/꿀팁 |
| 알림 | 이번 주 관리할 카테고리를 알려주는 가벼운 리마인드 |

### 7.2 제외 기능

- 세부 청소 항목별 주기 관리.
- 지연 카드, 연체/방치 중심 UX.
- 공동 가구, 담당자 배정, 구성원 초대.
- B2B 다중 공간 관리.
- 관리자 가이드 탭.
- 자체 결제, 장바구니, 배송, 환불.
- 업체 실시간 예약 API.
- 사진 기반 AI 진단.
- 자체 청소 인력 운영.
- 자체 크레딧 구독.

## 8. 정보 구조

```text
가칭 클린루프
├─ 홈
│  ├─ 이번 주 요약
│  ├─ 큰 카테고리 주기 카드
│  ├─ 카테고리 완료
│  ├─ 주기 수정
│  └─ 카테고리 추가
├─ 셀렉션
│  ├─ 오늘의 추천
│  ├─ 기본 청소템
│  ├─ 상황별 키트
│  ├─ 연결 가능한 서비스
│  └─ 추천 기준/제휴 고지
├─ 커뮤니티
│  ├─ 인기 꿀팁
│  ├─ 인기 Q&A
│  ├─ 꿀팁 공유 목록
│  └─ Q&A 목록
└─ 마이
   ├─ 청소 기록
   ├─ 완료 통계
   ├─ 저장한 셀렉션
   └─ 알림/주기 설정
```

홈과 주기 탭은 분리하지 않는다. 사용자가 가장 자주 들어오는 첫 화면이 곧 주기 관리 화면이어야 한다. 더 자세한 주기 설정은 홈의 카드 또는 `주기 편집` 진입점에서 시트로 제공한다.

## 9. 핵심 사용자 시나리오

### 시나리오 A: 사용자가 청소 주기를 관리한다

1. 사용자가 앱을 열면 홈에서 큰 카테고리 주기 카드가 보인다.
2. `욕실`, `주방`, `세탁/침구`, `쓰레기/수거`, `바닥/먼지`, `계절/가전` 같은 카테고리의 마지막 완료일과 다음 관리일을 확인한다.
3. 오늘 욕실 청소를 했다면 `완료`를 누른다.
4. 앱은 마지막 완료일을 오늘로 바꾸고 다음 관리일을 자동 계산한다.
5. 사용자는 주기 카드에서 반복 주기를 1주, 2주, 4주 등으로 수정할 수 있다.
6. 필요하면 새 큰 카테고리를 추가한다.

이 시나리오가 MVP의 가장 중요한 흐름이다. 용품 구매나 서비스 연결보다 먼저 검증해야 할 것은 사용자가 큰 카테고리 단위 주기 관리를 실제로 편하게 느끼는지다.

### 시나리오 B: 막히는 청소 문제를 커뮤니티에서 해결한다

1. 사용자가 욕실 청소 중 물때 제거 방법이 궁금해진다.
2. 커뮤니티에서 `꿀팁 공유` 또는 `Q&A`를 연다.
3. 상단에서 반응 많은 꿀팁이나 질문을 먼저 본다.
4. 비슷한 질문이 있으면 답변을 확인하고, 없으면 질문을 남긴다.
5. 좋은 팁은 저장해 나중에 다시 본다.

### 시나리오 C: 브랜드 셀렉션에서 용품이나 서비스를 참고한다

1. 사용자가 청소 도구가 필요하지만 무엇을 살지 모르겠다.
2. `셀렉션` 탭에서 카테고리별로 브랜드가 고른 용품과 키트를 본다.
3. 카드에는 `왜 골랐는지`, `어떤 상황에 맞는지`, `처음 쓰는 사람에게 쉬운지`, `제휴 여부`가 함께 표시된다.
4. 직접 하기 번거로운 카테고리는 연결 가능한 서비스 후보도 본다.
5. 사용자는 외부 판매처나 서비스 페이지로 이동할 수 있지만, 앱의 핵심은 구매 강요가 아니라 좋은 선택지를 소개하는 것이다.

## 10. 화면 구성안

### 10.1 홈

홈은 주기 관리 화면이다.

- 상단: 이번 주 관리 요약.
- 카테고리 카드: 큰 청소 카테고리, 추천 주기, 마지막 완료일, 다음 관리일.
- 카드 액션: 완료, 주기 수정, 도움 보기.
- 주기 편집 시트: 주기 단위 조정, 알림 여부, 카테고리 삭제/추가.
- 하단: 이번 달 완료 기록 요약.

표현 원칙:

- `지연`, `방치`, `연체` 같은 압박 표현을 핵심 카드에 쓰지 않는다.
- `오늘 하면 좋아요`, `이번 주에 챙기면 충분해요`처럼 다음 행동을 부드럽게 제안한다.
- 색상은 상태를 돕는 보조 장치로만 사용한다.

### 10.2 셀렉션

셀렉션은 커머스 탭이 아니라 브랜드가 운영하는 작은 청소 편집숍이다.

- 오늘의 셀렉션: 이번 주 관리 카테고리와 연결된 용품/서비스.
- 기본 청소템: 초보자에게 필요한 최소 용품.
- 상황별 키트: 장마철, 이사 직후, 욕실 관리, 세탁 관리.
- 서비스 연결: 세탁 수거, 문앞 수거, 부분 청소 등 외부 서비스 후보.
- 추천 기준: 초보자 사용성, 안전성, 가격 부담, 후기, 재구매성, 제휴 여부.

카드에는 다음을 표시한다.

- 추천 이름.
- 우리가 고른 이유.
- 맞는 상황.
- 가격대 또는 예상 비용.
- 제휴/비제휴 라벨.
- 외부 이동 안내.

### 10.3 커뮤니티

커뮤니티는 두 축만 둔다.

| 영역 | 역할 |
| --- | --- |
| 꿀팁 공유 | 사용자가 직접 써본 청소 방법, 도구, 루틴을 공유한다 |
| Q&A | 막히는 문제를 묻고 답한다 |

각 영역 상단에는 반응이 많은 글을 강조한다.

- 인기 꿀팁: 저장, 도움됨, 댓글이 많은 글.
- 인기 Q&A: 답변 수, 도움됨, 채택 여부가 높은 질문.

관리자 가이드는 MVP에서 별도 영역으로 두지 않는다. 운영자가 큐레이션한 정보가 필요하다면 셀렉션 카드나 커뮤니티 운영 추천 형태로 녹인다.

### 10.4 마이

- 이번 달 완료 수.
- 최근 완료 기록.
- 저장한 셀렉션.
- 내가 본 꿀팁/Q&A.
- 알림 설정.

공동 가구, 담당자, 구성원 관리는 MVP에서 제공하지 않는다.

## 12. 운영 정책

### 12.1 셀렉션 운영 원칙

1. 팔기 전에 고른 이유를 먼저 말한다.
2. 처음 쓰는 사람이 실수하기 쉬운 부분을 함께 적는다.
3. 가격은 범위 또는 확인 시점이 있는 예시로만 보여준다.
4. 제휴, 광고, 스폰서는 숨기지 않는다.
5. 구매하지 않고 해결 가능한 대체 방법이 있으면 함께 안내한다.
6. 서비스 연결은 `맡기는 것도 선택지`로 제안하되 기본값으로 밀지 않는다.

### 12.2 커뮤니티 운영 원칙

1. 꿀팁 공유와 Q&A를 명확히 나눈다.
2. 인기 글은 반응 지표로 상단에 올린다.
3. 광고성 글과 실제 경험 공유를 구분한다.
4. 위험한 세제 혼합, 과장된 효과, 검증되지 않은 방법은 운영자가 숨김 또는 경고 처리한다.
5. 커뮤니티 글에 상품/서비스 연결을 자동으로 붙이지 않는다.

### 12.3 알림 원칙

- 알림은 압박이 아니라 기억 보조다.
- 기본 빈도는 주 1회 이하로 시작한다.
- 문구는 `이번 주에 욕실 한 번 챙기면 좋아요`처럼 부드럽게 쓴다.
- `기한 초과`, `N일째 방치` 같은 표현은 피한다.

## 13. 성공 지표

### 13.1 North Star Metric

월간 카테고리 완료 기록 수

MVP에서 가장 중요한 행동은 사용자가 큰 청소 카테고리를 완료하고 다음 주기를 갱신하는 것이다. 구매, 예약, 커뮤니티 참여는 보조 지표로 본다.

### 13.2 핵심 지표

| 단계 | 지표 | 의미 |
| --- | --- | --- |
| 첫 사용 | 기본 카테고리 노출 후 홈 이탈률 | 초기 세팅 부담이 낮은가 |
| 활성화 | 첫 카테고리 완료율 | 사용자가 주기 관리 행동을 이해했는가 |
| 반복 | 주간 카테고리 완료 사용자 비율 | 주기 관리가 반복 사용으로 이어지는가 |
| 설정 | 주기 수정률 | 사용자가 자기 생활에 맞게 조정하는가 |
| 셀렉션 | 셀렉션 카드 저장률, 외부 이동률 | 브랜드가 고른 추천이 참고 가치가 있는가 |
| 커뮤니티 | 인기 꿀팁 조회율, Q&A 답변률 | 막히는 청소 문제를 함께 해결하는가 |
| 리텐션 | D7/D30 재방문율 | 주기 관리가 재방문 이유가 되는가 |

## 14. 차별화 포인트

1. 세부 항목 등록 없이 큰 카테고리 주기만으로 시작한다.
2. 홈과 주기를 분리하지 않아 첫 화면에서 바로 관리한다.
3. 지연으로 압박하지 않고, 다시 관리하기 쉬운 상태를 만든다.
4. 상품/서비스를 쇼핑몰처럼 나열하지 않고 브랜드 셀렉션처럼 소개한다.
5. 커뮤니티는 운영자 가이드보다 사용자 꿀팁과 Q&A에 집중한다.
6. 구매나 예약보다 청소 생활의 반복 관리가 중심이다.

## 16. 최종 의사결정 요약

- 서비스 한 줄 정의는 `오늘 관리할 일은 놓치지 않고, 막히는 청소 문제는 함께 해결하는 청소 생활 앱`으로 둔다.
- 서비스명은 확정 전까지 가칭으로만 사용한다.
- MVP 핵심은 큰 카테고리 기반 청소 주기 관리다.
- 홈과 주기 탭은 합친다.
- 지연 카드, 공동 가구, B2B 페르소나, 관리자 가이드는 제외한다.
- 해결 탭은 구매/예약 중심이 아니라 브랜드 셀렉션 중심으로 바꾼다.
- 커뮤니티는 꿀팁 공유와 Q&A, 그리고 인기 글 강조로 구성한다.
