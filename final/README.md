# 청소 생활 앱 최종 산출물

이 폴더는 청소 생활 앱의 최종 기획서, 원본 인사이트 요약, 실행 가능한 프로토타입을 담고 있다.

서비스명은 아직 확정 전이므로 문서와 화면에서는 가칭 `클린루프`로 표기한다.

## 구성

| 경로 | 내용 |
| --- | --- |
| `docs/final-plan.md` | 최종 통합 기획서 |
| `docs/source-analysis.md` | 원본 산출물 인사이트 요약 |
| `prototype/index.html` | 실행 가능한 정적 프로토타입 |
| `prototype/styles.css` | 프로토타입 스타일 |
| `prototype/app.js` | 프로토타입 상태와 인터랙션 로직 |

## 프로토타입 실행

브라우저에서 바로 열 수 있다.

```bash
open final/prototype/index.html
```

로컬 서버로 확인하려면 다음처럼 실행한다.

```bash
cd final/prototype
python3 -m http.server 4173
```

접속 주소:

```text
http://localhost:4173
```

## 제품 방향 요약

- 오늘 관리할 일은 놓치지 않고, 막히는 청소 문제는 함께 해결하는 청소 생활 앱.
- 큰 청소 카테고리를 기준으로 관리 리듬을 만든다.
- 사용자는 청소를 완료하고, 주기를 조정하고, 필요한 순간 도움을 찾는다.
- 커뮤니티는 꿀팁 공유와 Q&A를 중심으로 문제 해결을 돕는다.
- 셀렉션은 청소 용품과 서비스를 브랜드 관점으로 선별해 소개한다.
