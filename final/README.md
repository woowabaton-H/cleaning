# 클린루프 최종 산출물

이 폴더는 `huchu`, `if`, `몽이`, `테리`의 청소 서비스 기획과 프로토타입을 통합한 최종 결과물이다.

## 구성

| 경로 | 내용 |
| --- | --- |
| `docs/final-plan.md` | 최종 통합 기획서 |
| `docs/source-analysis.md` | 원본별 장점, 공통점, 채택/제외 요소 분석 |
| `prototype/index.html` | 실행 가능한 정적 프로토타입 |
| `prototype/styles.css` | 프로토타입 스타일 |
| `prototype/app.js` | 프로토타입 상태와 인터랙션 로직 |

## 프로토타입 실행

빌드나 설치 없이 브라우저에서 열 수 있다.

```bash
open final/prototype/index.html
```

로컬 서버로 확인하려면 다음처럼 실행할 수 있다.

```bash
cd final/prototype
python3 -m http.server 4173
```

접속 주소:

```text
http://localhost:4173
```

## 반영한 핵심 아이디어

- `huchu`: 주기, 커뮤니티, 청소템, 마이페이지 IA와 빠른 해결 시트.
- `if`: 상태에서 해결까지 이어지는 사업 루프, Task/Issue 구분, 중개/제휴 중심 수익 모델.
- `몽이`: 주간 클리어 루프, 알림에서 외주 예약으로 이어지는 시나리오, 청소발자국.
- `테리`: 클린루프와 보송이의 브랜드 계층, 전문가 기준선, 안전/업체 품질 정책.

## 프로토타입에서 체험 가능한 흐름

1. 홈에서 지연된 청소 상태 확인.
2. 지연 카드의 `방법`으로 문제 선택과 가이드 확인.
3. 청소템과 전문가 예약 비교.
4. 서비스, 공간/평수, 오염도, 일정 선택.
5. 업체 견적과 매칭 카드 비교.
6. 예약 확정 후 홈/주기/마이페이지에 반영.
7. 커뮤니티의 관리자 가이드에서 청소템/서비스로 연결.
8. 주기 보드에서 완료와 미루기 처리.

## MVP에서 제외한 것

- 실제 결제, 장바구니, 배송, 환불.
- 업체 실시간 API 연동.
- 로그인과 서버 저장.
- 사진 기반 AI 진단.
- 자체 구독 크레딧.
