# 청소 생활 앱 최종 산출물

이 폴더는 `huchu`, `if`, `몽이`, `테리`의 산출물을 검토한 뒤, 2026-07-10 기준 제품 방향으로 다시 정리한 최종 기획서와 실행 가능한 프로토타입이다.

서비스명은 아직 확정 전이므로 문서와 화면에서는 가칭 `클린루프`로 표기한다.

## 구성

| 경로 | 내용 |
| --- | --- |
| `docs/final-plan.md` | 문제 해결 중심의 최종 통합 기획서 |

| `prototype/index.html` | 실행 가능한 정적 프로토타입 |

| `prototype/app.js` | 프로토타입 상태와 인터랙션 로직 |

## 프로토타입 실행

설치 없이 브라우저에서 바로 열 수 있다.

```bash
open final/prototype/index.html
```

로컬 서버로 확인하려면 다음처럼 실행한다.

```bash
cd final/prototype
python3 -m http.server 4173
```

접속 주소:

```text
http://localhost:4173
```

## 이번 버전의 제품 방향

- 한 줄 정의: 오늘 관리할 일은 놓치지 않고, 막히는 청소 문제는 함께 해결하는 청소 생활 앱.
- MVP 핵심은 세부 청소 항목이 아니라 큰 카테고리 기반 청소 주기 관리다.
- 홈과 주기 탭을 분리하지 않고, 홈에서 주기 확인/완료/수정까지 처리한다.
- 용품과 서비스는 판매 목록이 아니라 브랜드가 고른 셀렉션처럼 보여준다.
- 커뮤니티는 관리자 가이드나 잡담이 아니라 꿀팁 공유와 Q&A에 집중한다.
- 공동 가구, B2B 관리자, 지연 카드, 자체 결제/배송, 실시간 예약 API는 MVP에서 제외한다.

## 프로토타입에서 체험 가능한 흐름

1. 홈에서 큰 청소 카테고리별 마지막 완료일과 다음 관리일을 확인한다.
2. 카테고리를 완료하면 다음 관리일과 월간 완료 기록이 갱신된다.
3. 홈 카드에서 주기를 3일, 7일, 14일, 21일, 28일 단위로 수정한다.
4. 막히는 카테고리는 셀렉션으로 이동해 브랜드가 고른 용품/서비스 후보를 본다.
5. 셀렉션 카드에서 추천 이유, 맞는 상황, 가격대, 제휴 여부를 확인하고 저장한다.
6. 커뮤니티에서 반응 좋은 꿀팁과 Q&A를 먼저 보고, 탭으로 목록을 전환한다.
7. 마이에서 월간 완료 수, 최근 완료 기록, 저장한 셀렉션을 확인한다.

## 원본별 반영 요약

- `huchu`: 주기 관리, 커뮤니티와 청소템 탐색을 분리하되 필요할 때 연결하는 구조.
- `if`: 직접 판매/구독보다 제휴·중개형 연결로 시작하는 현실적인 MVP 범위.
- `몽이`: 홈에서 주기 흐름을 관리하는 모바일 앱 감각과 청소발자국.
- `테리`: 브랜드 신뢰, 추천 근거, 안전성과 제휴 투명성 원칙.
