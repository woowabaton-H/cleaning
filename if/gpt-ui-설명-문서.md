# 보송 매니저 모바일 앱형 웹 UI 설계

## 1. 설계 기준

이번 UI는 일반 반응형 웹이 아니라 **모바일 가로폭 고정 인앱 프레임 구조**로 설계한다.

```text
Desktop Browser
  └─ 가운데 정렬된 390~430px 앱 프레임
       ├─ 고정 헤더
       ├─ 스크롤 가능한 콘텐츠
       └─ 고정 하단 탭바
```

목표는 웹에서 접속하더라도 사용자가 모바일 앱을 쓰는 것처럼 느끼게 하는 것이다. 상품/서비스 탐색, 주기 관리, 완료 기록이 모두 모바일 기준으로 정리되기 때문에 해커톤 프로토타입에서도 구현과 관리가 단순해진다.

## 2. 우선순위

1. 기획서의 핵심 루프를 화면에서 바로 이해할 수 있어야 한다.
2. 데스크톱에서도 모바일 앱처럼 보이는 고정 폭 구조를 사용한다.
3. 대시보드에서 사용자가 직접 `완료`를 누를 수 있어야 한다.
4. 캐릭터성은 남기되, 청소 서비스답게 밝고 깔끔해야 한다.
5. 이모지 중심 장식은 피하고, SVG 아이콘과 상태 배지로 통일한다.

## 3. 핵심 루프

```text
상태 확인
  → 문제 선택
  → 해결 가이드
  → 도구/업체 비교
  → 수동 완료 또는 신청 완료
  → 다음 주기 자동 갱신
```

이 루프를 홈, 청소하기, 주기 보드에서 반복적으로 접근할 수 있게 한다.

## 4. 하단 탭 구조

```text
[홈] [주기] [청소] [상점] [마이]
```

| 탭 | 역할 |
| --- | --- |
| 홈 | 이번 주 상태, 핵심가치, 지연/임박 항목, 수동 완료 |
| 주기 | 전체 청소 항목, 마지막 완료일, 미루기, 완료 |
| 청소 | 문제 카테고리 진입, 해결 플로우 시작 |
| 상점 | 상황별 청소 키트, 문제 기반 커머스 큐레이션 |
| 마이 | 청소 발자국, 기록, 공동 관리 확장 가능성 |

## 5. 주요 화면

### 홈

- 보송이 캐릭터와 한 줄 안내
- 핵심가치 4개 카드
- 이번 주 보송 스탬프
- 지금 확인할 항목
- 10분 안에 가능한 청소
- 각 항목의 `방법`, `맡기기`, `완료` 버튼

### 청소하기

- 6개 청소 카테고리
- 문제 선택 후 바텀시트로 해결 플로우 진입
- 단계: 문제 선택 → 가이드 → 도구/업체 비교 → 해결 완료

### 주기 보드

- 전체 / 욕실 / 주방 / 침구 / 수거 / 가전 필터
- 마지막 완료일, 목표 주기, 현재 상태 표시
- 수동 완료와 미루기 기능 제공

### 상점

- 찹스틱스처럼 모바일 커머스형 탐색 구조 참고
- 상품을 단순 나열하지 않고 상황별 키트로 큐레이션
- `추천`, `BEST`, `NEW`, `욕실`, `자취 시작` 같은 칩 필터 사용

### 마이

- 청소 발자국 기록
- 완료 방식 구분: SELF, COMMERCE, PARTNER
- 공동 관리 기능은 후순위 확장으로 표시

## 6. 캐릭터 사용 원칙

캐릭터는 서비스의 감정적 진입 장치로만 사용한다.

- 홈의 인사 영역
- 빈 상태
- 완료 피드백
- 과한 장식이 아닌 작은 SVG 캐릭터

가격 비교, 업체 비교, 완료 버튼처럼 판단이 필요한 화면에서는 캐릭터 노출을 줄인다.

## 7. 접근성 기준

- 하단 탭과 주요 버튼은 44px 이상의 터치 영역을 유지한다.
- 상태는 색상만으로 구분하지 않고 `정상`, `임박`, `지연` 텍스트를 함께 표시한다.
- 바텀시트는 `Escape`로 닫을 수 있다.
- 토스트는 `aria-live`로 상태 메시지를 전달한다.
- 애니메이션은 `prefers-reduced-motion`을 존중한다.
- 제휴/광고성 추천은 태그로 명시한다.

## 8. 이번 HTML 프로토타입에 반영된 기능

- 모바일 앱형 고정 프레임
- 하단 탭바
- 보송이 SVG 캐릭터
- 스탬프 카드
- 상태별 대시보드 카드
- 대시보드 수동 완료
- 주기 보드 수동 완료/미루기
- 바텀시트 기반 해결 플로우
- 도구/업체 비교 카드
- 상점 큐레이션 화면
- 청소 발자국 기록
