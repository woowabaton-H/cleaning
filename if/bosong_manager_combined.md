1. 버전명, 내부 작업 로그, 과한 표현은 제거한다.

5. 핵심 경험은 `상태 확인 → 문제 이해 → 해결 방법 → 도구/업체 연결 → 완료 후 주기 등록`으로 통일한다.
6. 공포 마케팅보다 다정한 재시작 톤을 사용한다.

# 보송 매니저 기획서

## 1. 서비스 한 줄 정의

보송 매니저는 집안의 청소 상태를 보여주고, 필요한 순간 해결 방법과 도구, 맡길 수 있는 서비스를 연결해 다음 관리 주기까지 이어주는 생활 관리 서비스다.

```text
상태가 알려주고, 해결까지 이어준다.
```

사용자는 청소 항목을 모두 직접 설계하지 않아도 된다. 앱은 기본 청소 카테고리와 권장 주기를 제공하고, 사용자는 지연되거나 임박한 항목을 눌러 문제를 확인한다. 이후 직접 해결 가이드, 필요한 용품, 맡길 수 있는 업체를 한 흐름 안에서 선택하고, 해결 완료 시 다음 주기가 자동으로 등록된다.

## 2. 핵심 결론

보송 매니저는 단순 청소 투두앱도, 단순 청소 업체 예약앱도 아니다.

```text
청소 주기를 보여주고,
문제 해결 방법을 알려주고,
필요한 도구와 서비스를 연결하고,
해결한 일을 다음 주기로 자동 관리하는 청소 문제 해결 플랫폼이다.
```

기존 청소 트래커는 `오늘 무엇을 해야 하는지`를 알려주지만, 사용자가 막히는 지점은 그 다음이다. 사용자는 `어떻게 해야 하는지`, `무엇을 사야 하는지`, `직접 해야 하는지`, `맡겨야 하는지`를 판단해야 한다. 보송 매니저는 이 판단 비용을 줄이는 서비스다.

## 3. 문제 정의

### 3.1 청소는 단순한 할 일이 아니다

청소는 일반 투두처럼 `화장실 청소하기`라고 적는 것만으로 해결되지 않는다. 사용자는 동시에 여러 질문을 해결해야 한다.

- 지금 무엇부터 해야 하는가?
- 이 청소는 얼마나 자주 해야 하는가?
- 어떤 도구나 세제가 필요한가?
- 이 얼룩, 냄새, 곰팡이는 직접 해결 가능한가?
- 전문가를 부르는 편이 더 나은가?
- 같이 사는 사람이 있다면 누가 맡아야 하는가?

즉, 청소를 미루는 이유는 단순히 의지가 약해서가 아니라 판단과 실행의 마찰이 크기 때문이다.

### 3.2 방치의 대가는 청소보다 비싸다

청소가 밀리면 곰팡이, 배수구 냄새, 초파리, 빨래 쉰내, 화장실 물때처럼 작은 문제가 커진다. 문제는 사용자가 방치하고 싶어서가 아니라 밀림이 눈에 잘 보이지 않는다는 점이다.

보송 매니저는 마지막 완료일과 권장 주기를 기준으로 상태를 보여준다. 정상, 임박, 지연 상태를 직관적으로 구분하고, 지연 항목은 바로 해결 플로우로 이어진다.

### 3.3 외주의 최소 단위가 크다

가사청소 서비스는 이미 존재하지만, 자취생이나 1인 가구가 일상적으로 쓰기에는 심리적 문턱이 있다. 4시간 단위 청소나 수만 원대 결제는 `이 정도면 내가 하고 말지`라는 생각을 만들고, 결국 청소도 외주도 함께 미뤄진다.

반면 문앞 수거, 세탁 수거, 특정 공간 집중 청소처럼 작은 단위로 쪼개진 서비스는 일상 소비로 들어올 가능성이 있다. 보송 매니저는 `집 전체 청소`가 아니라 `지금 밀린 문제 하나`에서 출발한다.

### 3.4 정보와 서비스가 파편화되어 있다

빨래는 세탁 앱, 쓰레기는 수거 앱, 가사청소는 청소 플랫폼, 용품은 쇼핑몰, 방법은 블로그나 유튜브에서 찾아야 한다. 사용자는 실행 전에 이미 여러 앱과 정보를 오가며 지친다.

보송 매니저는 문제 인식, 해결법, 용품, 업체, 다음 주기 등록을 한 흐름으로 묶는다.

### 3.5 같이 사는 사람과 역할을 나누기 어렵다

가족, 커플, 룸메이트가 함께 살면 청소는 생산성 문제가 아니라 공정성과 커뮤니케이션 문제가 된다. 보송 매니저는 담당자, 완료 기록, 자동 로테이션을 통해 한 사람이 계속 기억하고 지시하는 부담을 줄인다.

## 5. 페르소나

### 김보송, 26세, 직장인 2년차, 자취 3년차

- 평일 야근이 잦고 배달음식 비중이 높다.
- 작년 여름 욕실 곰팡이 때문에 주말 하루를 통째로 쓴 경험이 있다.
- 세탁 수거 서비스와 청소 플랫폼은 알지만 언제 무엇을 맡겨야 할지 몰라 사용하지 않았다.
- 청소 체크리스트 앱을 깔아봤지만 항목을 직접 등록하다가 며칠 만에 그만뒀다.
- 원하는 것은 완벽한 청소 관리가 아니라, 지금 무엇을 해야 하는지와 막혔을 때의 해결책이다.

## 10. 성공 지표

### 10.1 North Star Metric

```text
월간 해결된 청소 문제 수
```

단, 해결 방식을 나누어 본다.

- SELF: 직접 해결
- COMMERCE: 용품 구매 연결 후 해결
- PARTNER: 업체 문의/예약 연결 후 해결
- SUBSCRIPTION: 파트너 정기 서비스 연결 후 해결

SELF만 높으면 유틸리티 앱에 머문다. PARTNER와 COMMERCE가 함께 발생해야 사업 가설이 검증된다.

### 10.2 MVP 핵심 지표

| 단계 | 지표 | 의미 |

# 보송 매니저 사업 정보

## 1. 사업 관점 핵심 결론

보송 매니저의 초기 사업 모델은 자체 청소 구독권을 판매하는 것이 아니다. 초기에는 사용자의 청소 상태와 문제 데이터를 바탕으로 `전환 직전 수요`를 만들고, 그 수요를 용품 판매자와 청소 서비스 파트너에게 연결하는 중개형 모델로 시작한다.

```text
상태 데이터 → 문제 인식 → 해결 행동 → 용품/업체 전환
```

이 구조는 직접 청소 인력을 고용하거나 물류망을 운영하지 않기 때문에 초기 운영 리스크가 낮다.

## 2. 왜 자체 구독 크레딧을 핵심에서 제외하는가

팀 논의에서 나온 중요한 비판은 다음과 같다.

```text
청소 서비스가 비싸다는 문제를 말하면서,
사용자에게 월 5~6만 원대 구독을 제안하면 앞뒤가 맞지 않아 보일 수 있다.
```

따라서 MVP에서는 자체 크레딧 구독을 핵심 비즈니스 모델로 두지 않는다.

| 구분 | 판단 |
| --- | --- |
| 자체 크레딧 구독 | MVP 핵심에서 제외. 지불 의사와 원가 구조 검증 후 검토 |
| 파트너 정기구독 중개 | 유지. 이미 존재하는 파트너 요금제로 전환시키는 구조 |
| 프리미엄 앱 구독 | 후순위. 고급 알림, 가족 동기화, 기록 분석에서 가능 |
| 커머스/중개 수익 | MVP에서도 가장 현실적인 수익화 가설 |

## 4. 보송 매니저의 사업적 차별점

### 4.1 운영자가 아니라 중개자다

보송 매니저는 직접 청소 인력을 고용하지 않는다. 대신 사용자의 상태와 문제 데이터를 바탕으로 적절한 파트너를 연결한다.

```text
우리는 청소를 직접 수행하지 않는다.
우리는 청소가 필요한 순간을 포착하고, 가장 적합한 해결 수단으로 연결한다.
```

### 4.2 목적성 앱보다 접점이 잦다

가사청소 앱은 필요할 때만 열린다. 보송 매니저는 주기 관리와 문제 해결 콘텐츠를 통해 더 자주 열릴 수 있다. 자주 열리는 앱이 되면 용품 추천, 업체 연결, 파트너 구독 전환의 타이밍을 잡기 쉬워진다.

### 4.3 전환 직전 수요를 만든다

일반 배너 광고는 불특정 사용자에게 노출된다. 보송 매니저의 추천은 다르다.

```text
욕실 곰팡이가 11일 지연된 사용자에게 욕실 집중 청소 서비스를 보여준다.
빨래 주기가 밀린 사용자에게 세탁 수거 서비스를 보여준다.
소모품 교체 주기가 다가온 사용자에게 필요한 용품을 보여준다.
```

이 지점이 파트너에게 제안할 수 있는 핵심 가치다.

- 사용자 완료 기록과 후기 데이터를 통해 재예약 가능성을 높인다.

# 보송 매니저 브랜딩 기획

## 1. 브랜드 방향

보송 매니저는 사용자를 혼내는 청소 앱이 아니다. 청소를 잘 못하거나 미뤘더라도 다시 시작할 수 있게 돕는 생활 관리 브랜드다.

```text
막막함을 줄이고, 지금 가능한 선택지를 보여준다.
```

청소는 위생과 직결되지만, 공포를 과하게 자극하면 사용자는 반감을 느낄 수 있다. 보송 매니저의 톤은 `경고`보다 `안내`, `죄책감`보다 `재시작`, `명령`보다 `선택지`에 가깝다.

## 2. 브랜드 이름

| 항목 | 내용 |
| --- | --- |
| 서비스명 | 보송 매니저 |
| 의미 | 집을 보송한 상태로 유지하도록 돕는 생활 관리 도우미 |
| 인상 | 가볍고 친근하지만, 기능은 실용적 |

## 8. 마스코트 사용 원칙

마스코트는 필수 기능이 아니라 감정적 보조 장치다. 사용할 경우 다음 원칙을 지킨다.

1. 유니코드 이모지나 클립아트 느낌의 장식은 쓰지 않는다.
2. 직접 제작한 SVG 또는 일러스트만 사용한다.
3. 가격 비교, 업체 정보, 안전 주의사항에는 마스코트를 넣지 않는다.
4. 빈 상태, 완료, 재시작, 온보딩처럼 감정이 필요한 화면에만 사용한다.
5. 마스코트가 기능 이해를 방해하면 과감히 제거한다.

# 보송 매니저 운영 정보

## 1. 운영 정보의 목적

이 문서는 제품 안에서 실제로 다뤄야 할 청소 카테고리, 주기 계산 방식, 콘텐츠 구조, 용품/업체 데이터, 운영 정책을 정리한다.

핵심은 다음이다.

```text
사용자가 문제를 발견했을 때,
앱이 문제 이름을 붙이고,
해결 방법과 필요한 도구/서비스를 보여주고,
해결 후 다음 주기로 자동 전환한다.
```

## 4. 주기 계산 방식

### 4.1 기본 원칙

1. 마지막 완료일을 기준으로 다음 권장일을 계산한다.
2. 사용자가 직접 해결하든, 용품을 구매하든, 업체를 연결하든 `해결 완료`가 눌리면 주기가 갱신된다.
3. 실제 외부 서비스 완료 API가 없을 때는 신청일 기준으로 임시 완료 처리한다.
4. 사용자가 직접 날짜를 수정할 수 있어야 한다.
5. 이유를 설명할 수 없는 합성 점수는 쓰지 않는다.

### 4.2 계산 예시

```text
마지막 완료일 + 권장 주기 = 다음 권장일
```

| 항목 | 마지막 완료일 | 권장 주기 | 다음 권장일 |
| --- | --- | --- | --- |
| 욕실 곰팡이 점검 | 7월 1일 | 14일 | 7월 15일 |
| 침구 세탁 | 7월 3일 | 14일 | 7월 17일 |
| 배수구 청소 | 7월 8일 | 7일 | 7월 15일 |

### 4.3 파트너 서비스 신청 시

외부 업체 완료 API가 없는 초기에는 다음 방식으로 단순화한다.

```text
서비스 신청일 + 카테고리별 평균 소요일 = 완료 추정일
완료 추정일 + 권장 주기 = 다음 권장일
```

| 서비스 유형 | 평균 소요일 가정 |
| --- | --- |
| 일반 가사청소 | 1일 |
| 욕실 집중 청소 | 1일 |
| 문앞 수거 | 1일 |
| 세탁 수거 | 2~3일 |
| 에어컨/세탁기 청소 | 1~3일 |

### 8.3 추천 원칙

1. 가이드와 관련 없는 상품을 과하게 노출하지 않는다.
2. 왜 이 상품이 필요한지 설명한다.
3. 광고/제휴/스폰서 상품은 명확히 표시한다.
4. 사용자가 이미 보유한 도구를 등록하면 중복 추천을 줄인다.
5. 구매하지 않고도 가능한 대체 방법을 함께 제공한다.

  상태 긴급도 30%

# 보송 매니저 UI/UX 기획

## 1. UI/UX 핵심 원칙

1. 청소 서비스답게 화면은 밝고 단순해야 한다.
2. 한 화면에서 한 가지 판단만 유도한다.
3. 사용자가 초반에 많은 정보를 입력하지 않게 한다.
4. 상태를 보여주고, 필요한 항목만 행동 가능하게 한다.
5. 직접 해결과 맡기기를 같은 흐름 안에서 선택하게 한다.
6. 광고/제휴는 숨기지 않는다.
7. 이모지나 과한 장식 대신 일관된 카드, 배지, 상태 색을 사용한다.

## 2. 하단 네비게이션

MVP에서는 탭을 줄인다.

```text
[홈]   [청소하기]   [주기 보드]   [커머스]   [마이]
```

| 탭 | 역할 | MVP 포함 여부 |
| --- | --- | --- |
| 홈 | 오늘의 상태, 지연/임박 항목, 핵심 진입 | 포함 |
| 청소하기 | 문제 카테고리, 가이드, 도구/업체 비교 | 포함 |
| 주기 보드 | 전체 작업과 다음 권장일 관리 | 포함 |
| 커머스 | 청소 용품과 키트 추천 | 간단 포함 또는 후순위 |
| 마이 | 기록, 설정, 알림, 공동 관리 | 최소 포함 |

커뮤니티는 별도 탭으로 두지 않고, 초기에는 홈 또는 커머스 안의 `청소 팁` 카드로 시작한다.

## 3. 핵심 화면 구조

### 3.1 홈

홈은 사용자가 앱을 열었을 때 바로 실행할 수 있는 화면이어야 한다.

필수 구성:

- 이번 주 집 상태 요약
- 스탬프 카드 또는 상태 카드
- 지금 확인이 필요한 항목
- 10분 안에 가능한 청소
- 직접 하기 어려운 항목
- 곧 필요한 소모품
- 최근 해결한 문제

### 와이어프레임

```text
┌──────────────────────────────┐
│ 보송 매니저              알림 │
│ 이번 주 집 상태를 확인했어요 │
│ 욕실과 쓰레기만 챙기면 충분해요 │
├──────────────────────────────┤
│ 이번 주 보송 스탬프           │
│ [침구] [욕실] [주방] [수거] [바닥] [가전] │
│ 정상   지연   정상   임박   정상   정상  │
├──────────────────────────────┤
│ 지금 확인할 항목              │
│ 욕실 곰팡이 점검이 밀렸어요   │
│ [방법 보기] [업체 보기]       │
├──────────────────────────────┤
│ 10분 안에 가능한 청소         │
│ 배수구 머리카락 정리          │
└──────────────────────────────┘
```

## 4. 스탬프 카드

스탬프 카드는 상태 기반 진입점이다.

| 상태 | 표현 | 행동 가능 여부 |
| --- | --- | --- |
| 정상 | 초록 또는 연한 체크 배지 | 클릭 불가 또는 상세만 보기 |
| 임박 | 노랑 배지 | 알림/준비물 보기 가능 |
| 지연 | 분홍/코랄 테두리 또는 강조 배지 | 해결 플로우 진입 가능 |

정상 항목까지 모두 클릭 가능하게 만들면 사용자는 무엇이 중요한지 헷갈린다. 지금 조치가 필요한 항목만 행동 가능하게 두는 것이 더 명확하다.

## 6. 도구/업체 비교 화면

`가격 비교형 게이트웨이`의 핵심 화면이다. 외부 서비스명을 직접 비유하지 않고, 사용자가 비교해야 할 정보를 카드로 보여준다.

### 6.1 도구 카드

| 정보 | 예시 |
| --- | --- |
| 제품명 | 욕실 곰팡이 제거젤 |
| 적합 문제 | 타일 줄눈 곰팡이 |
| 가격대 | 3,000~8,000원 |
| 판매처 | 다이소, 온라인몰, B마트 등 |
| 추천 이유 | 좁은 줄눈에 바르기 쉬움 |
| 주의 | 환기 필요, 다른 세제와 혼합 금지 |

### 6.2 업체 카드

| 정보 | 예시 |
| --- | --- |
| 업체명 | 욕실 집중 청소 파트너 |
| 가격대 | 35,000원부터 |
| 가능 지역 | 서울 일부 지역 |
| 제공 범위 | 욕실 바닥, 세면대, 줄눈, 배수구 |
| 제외 범위 | 실리콘 재시공, 타일 교체 |
| CTA | 견적 보기, 예약 문의 |
| 라벨 | 제휴, 광고, 인기, 빠른 일정 등 |

### 와이어프레임

```text
┌──────────────────────────────┐
│ 도구와 맡길 곳을 비교해볼게요 │
├──────────────────────────────┤
│ 직접 해결 도구                │
│ 곰팡이 제거젤 3,900원부터     │
│ [가격 비교]                   │
├──────────────────────────────┤
│ 맡길 수 있는 서비스            │
│ 욕실 집중 청소 39,000원부터   │
│ 제공 범위 / 후기 / 가능 지역  │
│ [견적 보기]                   │
├──────────────────────────────┤
│ [해결 완료]                   │
└──────────────────────────────┘
```

- 권장 주기
- 다음 권장일
- 상태
- 담당자

## 8. 알림

알림은 사용자를 압박하는 도구가 아니라 다시 시작하게 돕는 장치다.

| 알림 유형 | 예시 문구 | 연결 화면 |
| --- | --- | --- |
| 지연 알림 | 욕실 곰팡이 점검 시점이 지났어요. 오늘은 방법만 확인해도 괜찮아요. | 해결 가이드 |
| 임박 알림 | 이번 주 안에 침구를 세탁하면 좋아요. | 세탁 가이드/수거 서비스 |
| 소모품 알림 | 수세미 교체 시점이 가까워요. | 커머스 카드 |
| 파트너 알림 | 쓰레기 수거가 자주 밀린다면 정기 수거도 볼 수 있어요. | 파트너 랜딩 |

## 9. 커머스 화면

초기 커머스는 쇼핑몰이 아니라 문제 해결 도구 모음에 가깝게 설계한다.

구성:

- 문제별 추천 용품
- 자취 초보 키트
- 장마철 곰팡이 키트
- 욕실 물때 키트
- 배수구 냄새 키트
- 보유 도구 등록
- 광고/제휴 표시

## 11. 프로토타입 데모 시나리오

### 시나리오 A: 직접 해결

1. 홈에서 욕실 곰팡이 지연 카드 확인
2. 카드 선택
3. 타일 곰팡이 문제 선택
4. 가이드 확인
5. 필요한 도구 확인
6. 해결 완료 선택
7. 주기 보드에 다음 점검일 자동 등록

### 시나리오 B: 맡기기

1. 홈 알림에서 쓰레기 수거 지연 확인
2. 알림 선택
3. 파트너 랜딩 진입
4. 요금제 또는 업체 카드 비교
5. `문의하기` 또는 `시작하기` 선택
6. 해당 카테고리 상태가 해결 예정으로 변경
