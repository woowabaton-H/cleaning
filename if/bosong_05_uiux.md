# 보송 매니저 UI/UX 기획

## 1. UI/UX 핵심 원칙

1. 청소 서비스답게 화면은 밝고 단순해야 한다.
2. 한 화면에서 한 가지 판단만 유도한다.
3. 사용자가 초반에 많은 정보를 입력하지 않게 한다.
4. 상태를 보여주고, 필요한 항목만 행동 가능하게 한다.
5. 직접 해결과 맡기기를 같은 흐름 안에서 선택하게 한다.
6. 광고/제휴는 숨기지 않는다.
7. 이모지나 과한 장식 대신 일관된 카드, 배지, 상태 색을 사용한다.

## 2. 하단 네비게이션

MVP에서는 탭을 줄인다.

```text
[홈]   [청소하기]   [주기 보드]   [커머스]   [마이]
```

| 탭 | 역할 | MVP 포함 여부 |
| --- | --- | --- |
| 홈 | 오늘의 상태, 지연/임박 항목, 핵심 진입 | 포함 |
| 청소하기 | 문제 카테고리, 가이드, 도구/업체 비교 | 포함 |
| 주기 보드 | 전체 작업과 다음 권장일 관리 | 포함 |
| 커머스 | 청소 용품과 키트 추천 | 간단 포함 또는 후순위 |
| 마이 | 기록, 설정, 알림, 공동 관리 | 최소 포함 |

커뮤니티는 별도 탭으로 두지 않고, 초기에는 홈 또는 커머스 안의 `청소 팁` 카드로 시작한다.

## 3. 핵심 화면 구조

### 3.1 홈

홈은 사용자가 앱을 열었을 때 바로 실행할 수 있는 화면이어야 한다.

필수 구성:

- 이번 주 집 상태 요약
- 스탬프 카드 또는 상태 카드
- 지금 확인이 필요한 항목
- 10분 안에 가능한 청소
- 직접 하기 어려운 항목
- 곧 필요한 소모품
- 최근 해결한 문제

### 와이어프레임

```text
┌──────────────────────────────┐
│ 보송 매니저              알림 │
│ 이번 주 집 상태를 확인했어요 │
│ 욕실과 쓰레기만 챙기면 충분해요 │
├──────────────────────────────┤
│ 이번 주 보송 스탬프           │
│ [침구] [욕실] [주방] [수거] [바닥] [가전] │
│ 정상   지연   정상   임박   정상   정상  │
├──────────────────────────────┤
│ 지금 확인할 항목              │
│ 욕실 곰팡이 점검이 밀렸어요   │
│ [방법 보기] [업체 보기]       │
├──────────────────────────────┤
│ 10분 안에 가능한 청소         │
│ 배수구 머리카락 정리          │
└──────────────────────────────┘
```

## 4. 스탬프 카드

스탬프 카드는 상태 기반 진입점이다.

| 상태 | 표현 | 행동 가능 여부 |
| --- | --- | --- |
| 정상 | 초록 또는 연한 체크 배지 | 클릭 불가 또는 상세만 보기 |
| 임박 | 노랑 배지 | 알림/준비물 보기 가능 |
| 지연 | 분홍/코랄 테두리 또는 강조 배지 | 해결 플로우 진입 가능 |

정상 항목까지 모두 클릭 가능하게 만들면 사용자는 무엇이 중요한지 헷갈린다. 지금 조치가 필요한 항목만 행동 가능하게 두는 것이 더 명확하다.

## 5. 청소하기 플로우

### 5.1 기본 흐름

```text
STEP 1. 카테고리 확인
STEP 2. 세부 문제 선택
STEP 3. 해결 가이드 확인
STEP 4. 도구/업체 비교
STEP 5. 해결 완료
STEP 6. 다음 주기 자동 등록
```

### 5.2 화면 구조

```text
┌──────────────────────────────┐
│ STEP 2 / 5  욕실 문제 선택     │
│ 뒤로가기                  닫기 │
├──────────────────────────────┤
│ 어떤 문제가 가장 가까운가요?   │
│                              │
│ [타일 곰팡이]                 │
│ [배수구 냄새]                 │
│ [샤워부스 물때]               │
│ [변기 얼룩]                   │
└──────────────────────────────┘
```

### 5.3 가이드 화면

```text
┌──────────────────────────────┐
│ 타일 곰팡이 정리              │
│ 예상 15분 · 난이도 보통       │
├──────────────────────────────┤
│ 먼저 확인할 것                │
│ 환기하고 장갑을 착용하세요     │
├──────────────────────────────┤
│ 준비물                        │
│ 곰팡이 제거젤, 솔, 장갑        │
├──────────────────────────────┤
│ 순서                          │
│ 1. 물기를 제거합니다           │
│ 2. 제거젤을 바릅니다           │
│ 3. 일정 시간 뒤 문지릅니다     │
├──────────────────────────────┤
│ [도구 보기] [업체 보기]        │
└──────────────────────────────┘
```

## 6. 도구/업체 비교 화면

`가격 비교형 게이트웨이`의 핵심 화면이다. 외부 서비스명을 직접 비유하지 않고, 사용자가 비교해야 할 정보를 카드로 보여준다.

### 6.1 도구 카드

| 정보 | 예시 |
| --- | --- |
| 제품명 | 욕실 곰팡이 제거젤 |
| 적합 문제 | 타일 줄눈 곰팡이 |
| 가격대 | 3,000~8,000원 |
| 판매처 | 다이소, 온라인몰, B마트 등 |
| 추천 이유 | 좁은 줄눈에 바르기 쉬움 |
| 주의 | 환기 필요, 다른 세제와 혼합 금지 |

### 6.2 업체 카드

| 정보 | 예시 |
| --- | --- |
| 업체명 | 욕실 집중 청소 파트너 |
| 가격대 | 35,000원부터 |
| 가능 지역 | 서울 일부 지역 |
| 제공 범위 | 욕실 바닥, 세면대, 줄눈, 배수구 |
| 제외 범위 | 실리콘 재시공, 타일 교체 |
| CTA | 견적 보기, 예약 문의 |
| 라벨 | 제휴, 광고, 인기, 빠른 일정 등 |

### 와이어프레임

```text
┌──────────────────────────────┐
│ 도구와 맡길 곳을 비교해볼게요 │
├──────────────────────────────┤
│ 직접 해결 도구                │
│ 곰팡이 제거젤 3,900원부터     │
│ [가격 비교]                   │
├──────────────────────────────┤
│ 맡길 수 있는 서비스            │
│ 욕실 집중 청소 39,000원부터   │
│ 제공 범위 / 후기 / 가능 지역  │
│ [견적 보기]                   │
├──────────────────────────────┤
│ [해결 완료]                   │
└──────────────────────────────┘
```

## 7. 주기 보드

주기 보드는 전체 청소 상태를 관리하는 전용 화면이다.

필수 정보:

- 작업명
- 공간/카테고리
- 마지막 완료일
- 권장 주기
- 다음 권장일
- 상태
- 담당자
- 완료/미루기/수정 버튼

### 와이어프레임

```text
┌──────────────────────────────┐
│ 주기 보드                     │
│ 전체 / 욕실 / 주방 / 침구 / 수거 │
├──────────────────────────────┤
│ 욕실 곰팡이 점검              │
│ 마지막 7월 1일 · 11일 지연    │
│ [방법 보기] [완료] [미루기]    │
├──────────────────────────────┤
│ 침구 세탁                     │
│ 다음 3일 뒤                   │
│ [세탁 수거 보기] [완료]        │
└──────────────────────────────┘
```

## 8. 알림

알림은 사용자를 압박하는 도구가 아니라 다시 시작하게 돕는 장치다.

| 알림 유형 | 예시 문구 | 연결 화면 |
| --- | --- | --- |
| 지연 알림 | 욕실 곰팡이 점검 시점이 지났어요. 오늘은 방법만 확인해도 괜찮아요. | 해결 가이드 |
| 임박 알림 | 이번 주 안에 침구를 세탁하면 좋아요. | 세탁 가이드/수거 서비스 |
| 소모품 알림 | 수세미 교체 시점이 가까워요. | 커머스 카드 |
| 파트너 알림 | 쓰레기 수거가 자주 밀린다면 정기 수거도 볼 수 있어요. | 파트너 랜딩 |

## 9. 커머스 화면

초기 커머스는 쇼핑몰이 아니라 문제 해결 도구 모음에 가깝게 설계한다.

구성:

- 문제별 추천 용품
- 자취 초보 키트
- 장마철 곰팡이 키트
- 욕실 물때 키트
- 배수구 냄새 키트
- 보유 도구 등록
- 광고/제휴 표시

## 10. 마이페이지

MVP에서는 마이페이지를 가볍게 둔다.

- 완료 기록
- 알림 설정
- 공간/가구 설정
- 담당자 설정
- 보유 도구
- 제휴/광고 안내
- 개인정보/계정 설정

## 11. 프로토타입 데모 시나리오

### 시나리오 A: 직접 해결

1. 홈에서 욕실 곰팡이 지연 카드 확인
2. 카드 선택
3. 타일 곰팡이 문제 선택
4. 가이드 확인
5. 필요한 도구 확인
6. 해결 완료 선택
7. 주기 보드에 다음 점검일 자동 등록

### 시나리오 B: 맡기기

1. 홈 알림에서 쓰레기 수거 지연 확인
2. 알림 선택
3. 파트너 랜딩 진입
4. 요금제 또는 업체 카드 비교
5. `문의하기` 또는 `시작하기` 선택
6. 해당 카테고리 상태가 해결 예정으로 변경

## 12. 개발 우선순위

| 우선순위 | 기능 | 이유 |
| --- | --- | --- |
| 1 | 홈 상태 카드 | 서비스 가치를 가장 빨리 보여줌 |
| 2 | 해결 플로우 | 차별점의 핵심 |
| 3 | 가이드/도구/업체 정적 데이터 | 실제 연동 없이도 데모 가능 |
| 4 | 해결 완료 후 주기 등록 | 루프 완성 |
| 5 | 주기 보드 | 반복 사용 근거 |
| 6 | 알림/파트너 랜딩 | 수익화 가설 시연 |
| 7 | 커머스 | 제휴 수익 가설 시연 |
