# 보송 매니저 브랜딩 기획

## 1. 브랜드 방향

보송 매니저는 사용자를 혼내는 청소 앱이 아니다. 청소를 잘 못하거나 미뤘더라도 다시 시작할 수 있게 돕는 생활 관리 브랜드다.

```text
막막함을 줄이고, 지금 가능한 선택지를 보여준다.
```

청소는 위생과 직결되지만, 공포를 과하게 자극하면 사용자는 반감을 느낄 수 있다. 보송 매니저의 톤은 `경고`보다 `안내`, `죄책감`보다 `재시작`, `명령`보다 `선택지`에 가깝다.

## 2. 브랜드 이름

| 항목 | 내용 |
| --- | --- |
| 서비스명 | 보송 매니저 |
| 의미 | 집을 보송한 상태로 유지하도록 돕는 생활 관리 도우미 |
| 인상 | 가볍고 친근하지만, 기능은 실용적 |
| 사용 원칙 | 발표와 문서에서 서비스명은 보송 매니저로 통일 |

## 3. 슬로건 후보

### 메인 후보

```text
깨끗한 집은 의지가 아니라 시스템으로 유지됩니다.
```

### 보조 후보

```text
밀린 청소를 보여주고, 해결까지 이어줍니다.
```

```text
오늘 할 청소를 작게 나누고, 필요하면 맡길 수 있게.
```

```text
집안일이 막막할 때, 보송 매니저가 다음 행동을 알려줍니다.
```

## 4. 톤앤매너

| 원칙 | 설명 |
| --- | --- |
| 다정함 | 사용자를 비난하지 않는다 |
| 명확함 | 해야 할 행동을 짧게 보여준다 |
| 재시작 | 밀린 상태를 실패가 아니라 다시 시작할 시점으로 표현한다 |
| 실용성 | 귀여움보다 해결 가능성을 먼저 보여준다 |
| 투명성 | 광고, 제휴, 업체 추천은 숨기지 않는다 |
| 선택권 | 직접 하기와 맡기기를 동등한 선택지로 둔다 |

## 5. 피해야 할 표현

| 피해야 할 톤 | 이유 | 대체 표현 |
| --- | --- | --- |
| 더럽다, 방치했다, 큰일 났다 | 사용자가 공격받는 느낌을 받을 수 있음 | 조금 밀렸어요, 이번 주에 정리하면 좋아요 |
| 세균 폭탄, 탈모 유발, 피부 망가짐 | 공포 마케팅으로 보일 수 있음 | 위생 관리가 필요한 시점이에요 |
| 빨리 청소하세요 | 명령형이라 피로감이 큼 | 오늘 5분만 정리해볼까요? |
| 이 정도는 해야죠 | 죄책감을 유발함 | 작은 단계부터 다시 시작해요 |
| 무조건 전문가 필요 | 과장/광고처럼 보임 | 직접 하기 번거롭다면 맡길 수 있어요 |

## 6. 권장 문구 예시

| 상황 | 문구 |
| --- | --- |
| 정상 | 아직 괜찮아요. 다음 점검일에 다시 알려드릴게요. |
| 임박 | 이번 주 안에 하면 다음 청소가 쉬워져요. |
| 지연 | 조금 밀렸지만 괜찮아요. 5분짜리 방법부터 볼까요? |
| 가이드 진입 | 필요한 도구와 순서를 먼저 확인해볼게요. |
| 용품 추천 | 이 문제에는 물때 제거제가 더 잘 맞아요. |
| 업체 연결 | 직접 하기 번거롭다면 욕실 집중 청소를 맡길 수 있어요. |
| 완료 | 해결했어요. 다음 점검은 3주 뒤에 알려드릴게요. |
| 알림 | 욕실 곰팡이 점검 시점이 지났어요. 오늘은 방법만 확인해도 괜찮아요. |

## 7. 디자인 키워드

```text
밝음, 여백, 깨끗함, 친근함, 상태가 잘 보이는 카드 UI
```

| 요소 | 방향 |
| --- | --- |
| 색상 | 흰색, 밝은 하늘색, 코발트 블루, 민트 그린 중심 |
| 강조색 | 노랑은 임박, 코랄/분홍은 지연에만 제한적으로 사용 |
| 배경 | 흰색 또는 매우 연한 블루 |
| 카드 | 둥근 모서리, 충분한 여백, 약한 보더 |
| 텍스트 | 한 화면에서 한 가지 판단만 가능하게 짧게 |
| 그림 | 즉흥적 이모지보다 일관된 커스텀 일러스트 사용 |

## 8. 마스코트 사용 원칙

마스코트는 필수 기능이 아니라 감정적 보조 장치다. 사용할 경우 다음 원칙을 지킨다.

1. 유니코드 이모지나 클립아트 느낌의 장식은 쓰지 않는다.
2. 직접 제작한 SVG 또는 일러스트만 사용한다.
3. 가격 비교, 업체 정보, 안전 주의사항에는 마스코트를 넣지 않는다.
4. 빈 상태, 완료, 재시작, 온보딩처럼 감정이 필요한 화면에만 사용한다.
5. 마스코트가 기능 이해를 방해하면 과감히 제거한다.

## 9. 캐치프레이즈 구조

### 문제 인식형

```text
청소가 어려운 건 게을러서가 아니라, 어디서부터 해야 할지 모르기 때문입니다.
```

### 해결 연결형

```text
보송 매니저는 밀린 청소를 보여주고, 방법과 도구와 맡길 곳까지 이어줍니다.
```

### 재발 방지형

```text
한 번 해결한 청소는 다음 주기까지 자동으로 관리합니다.
```

### 발표 엔딩형

```text
깨끗한 집은 의지가 아니라 시스템으로 유지됩니다.
보송 매니저는 그 시스템을 가장 가볍게 시작하게 만듭니다.
```

## 10. 브랜드 보이스 샘플

### 홈 상단

```text
이번 주 집 상태를 확인했어요.
지금은 욕실과 쓰레기만 챙기면 충분해요.
```

### 지연 카드

```text
욕실 곰팡이 점검이 조금 밀렸어요.
오늘은 10분짜리 방법부터 확인해볼까요?
```

### 업체 연결

```text
직접 할 수도 있지만 시간이 꽤 걸릴 수 있어요.
이번에는 맡기는 선택지도 함께 볼게요.
```

### 완료 후

```text
좋아요. 이번 문제는 해결됐어요.
다음 점검일에 다시 알려드릴게요.
```
