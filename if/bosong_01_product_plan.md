# 보송 매니저 기획서

## 1. 서비스 한 줄 정의

보송 매니저는 집안의 청소 상태를 보여주고, 필요한 순간 해결 방법과 도구, 맡길 수 있는 서비스를 연결해 다음 관리 주기까지 이어주는 생활 관리 서비스다.

```text
상태가 알려주고, 해결까지 이어준다.
```

사용자는 청소 항목을 모두 직접 설계하지 않아도 된다. 앱은 기본 청소 카테고리와 권장 주기를 제공하고, 사용자는 지연되거나 임박한 항목을 눌러 문제를 확인한다. 이후 직접 해결 가이드, 필요한 용품, 맡길 수 있는 업체를 한 흐름 안에서 선택하고, 해결 완료 시 다음 주기가 자동으로 등록된다.

## 2. 핵심 결론

보송 매니저는 단순 청소 투두앱도, 단순 청소 업체 예약앱도 아니다.

```text
청소 주기를 보여주고,
문제 해결 방법을 알려주고,
필요한 도구와 서비스를 연결하고,
해결한 일을 다음 주기로 자동 관리하는 청소 문제 해결 플랫폼이다.
```

기존 청소 트래커는 `오늘 무엇을 해야 하는지`를 알려주지만, 사용자가 막히는 지점은 그 다음이다. 사용자는 `어떻게 해야 하는지`, `무엇을 사야 하는지`, `직접 해야 하는지`, `맡겨야 하는지`를 판단해야 한다. 보송 매니저는 이 판단 비용을 줄이는 서비스다.

## 3. 문제 정의

### 3.1 청소는 단순한 할 일이 아니다

청소는 일반 투두처럼 `화장실 청소하기`라고 적는 것만으로 해결되지 않는다. 사용자는 동시에 여러 질문을 해결해야 한다.

- 지금 무엇부터 해야 하는가?
- 이 청소는 얼마나 자주 해야 하는가?
- 어떤 도구나 세제가 필요한가?
- 이 얼룩, 냄새, 곰팡이는 직접 해결 가능한가?
- 전문가를 부르는 편이 더 나은가?
- 같이 사는 사람이 있다면 누가 맡아야 하는가?

즉, 청소를 미루는 이유는 단순히 의지가 약해서가 아니라 판단과 실행의 마찰이 크기 때문이다.

### 3.2 방치의 대가는 청소보다 비싸다

청소가 밀리면 곰팡이, 배수구 냄새, 초파리, 빨래 쉰내, 화장실 물때처럼 작은 문제가 커진다. 문제는 사용자가 방치하고 싶어서가 아니라 밀림이 눈에 잘 보이지 않는다는 점이다.

보송 매니저는 마지막 완료일과 권장 주기를 기준으로 상태를 보여준다. 정상, 임박, 지연 상태를 직관적으로 구분하고, 지연 항목은 바로 해결 플로우로 이어진다.

### 3.3 외주의 최소 단위가 크다

가사청소 서비스는 이미 존재하지만, 자취생이나 1인 가구가 일상적으로 쓰기에는 심리적 문턱이 있다. 4시간 단위 청소나 수만 원대 결제는 `이 정도면 내가 하고 말지`라는 생각을 만들고, 결국 청소도 외주도 함께 미뤄진다.

반면 문앞 수거, 세탁 수거, 특정 공간 집중 청소처럼 작은 단위로 쪼개진 서비스는 일상 소비로 들어올 가능성이 있다. 보송 매니저는 `집 전체 청소`가 아니라 `지금 밀린 문제 하나`에서 출발한다.

### 3.4 정보와 서비스가 파편화되어 있다

빨래는 세탁 앱, 쓰레기는 수거 앱, 가사청소는 청소 플랫폼, 용품은 쇼핑몰, 방법은 블로그나 유튜브에서 찾아야 한다. 사용자는 실행 전에 이미 여러 앱과 정보를 오가며 지친다.

보송 매니저는 문제 인식, 해결법, 용품, 업체, 다음 주기 등록을 한 흐름으로 묶는다.

### 3.5 같이 사는 사람과 역할을 나누기 어렵다

가족, 커플, 룸메이트가 함께 살면 청소는 생산성 문제가 아니라 공정성과 커뮤니케이션 문제가 된다. 보송 매니저는 담당자, 완료 기록, 자동 로테이션을 통해 한 사람이 계속 기억하고 지시하는 부담을 줄인다.

## 5. 페르소나

### 김보송, 26세, 직장인 2년차, 자취 3년차

- 평일 야근이 잦고 배달음식 비중이 높다.
- 작년 여름 욕실 곰팡이 때문에 주말 하루를 통째로 쓴 경험이 있다.
- 세탁 수거 서비스와 청소 플랫폼은 알지만 언제 무엇을 맡겨야 할지 몰라 사용하지 않았다.
- 청소 체크리스트 앱을 깔아봤지만 항목을 직접 등록하다가 며칠 만에 그만뒀다.
- 원하는 것은 완벽한 청소 관리가 아니라, 지금 무엇을 해야 하는지와 막혔을 때의 해결책이다.

## 7. 제품 포지셔닝

### 7.1 포지셔닝 문장

보송 매니저는 청소를 잘 모르는 사람도 집을 지속적으로 관리할 수 있도록, 청소 상태와 문제 해결 지식과 용품/서비스 연결을 하나로 묶은 생활 관리 앱이다.

### 7.2 경쟁 범주 대비 차별점

| 구분 | 기존 서비스 | 보송 매니저 |
| --- | --- | --- |
| 청소 트래커 | 주기와 체크리스트 중심 | 상태에서 해결까지 이어짐 |
| 청소 플랫폼 | 업체 예약 중심 | 사용자가 문제를 느끼는 순간부터 연결 |
| 쇼핑몰 | 상품 나열 중심 | 문제와 주기에 맞는 용품 추천 |
| 검색/블로그/유튜브 | 정보는 많지만 흩어져 있음 | 문제별 해결법, 주의사항, 도구, 업체를 구조화 |
| 커뮤니티 | 후기와 팁 중심 | 실제 해결 기록과 주기 데이터로 신뢰 보강 |

## 10. 성공 지표

### 10.1 North Star Metric

```text
월간 해결된 청소 문제 수
```

단, 해결 방식을 나누어 본다.

- SELF: 직접 해결
- COMMERCE: 용품 구매 연결 후 해결
- PARTNER: 업체 문의/예약 연결 후 해결
- SUBSCRIPTION: 파트너 정기 서비스 연결 후 해결

SELF만 높으면 유틸리티 앱에 머문다. PARTNER와 COMMERCE가 함께 발생해야 사업 가설이 검증된다.

### 10.2 MVP 핵심 지표

| 단계 | 지표 | 의미 |
| --- | --- | --- |
| 유입 | 홈 진입 후 지연 카드 클릭률 | 상태 표시가 행동을 유도하는가 |
| 활성화 | 첫 문제 가이드 조회율 | 사용자가 문제 해결 콘텐츠를 찾는가 |
| 실행 | 가이드 완료율 | 콘텐츠가 실제 행동으로 이어지는가 |
| 전환 | 용품/업체 카드 클릭률 | 실행 연결이 유효한가 |
| 반복 | 해결 후 다음 주기 재방문율 | 주기 관리가 리텐션을 만드는가 |
| 수익 | 구매 전환율, 예약/견적 요청률 | 사업 모델이 작동하는가 |
