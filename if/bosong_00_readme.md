# 보송 매니저 문서 묶음 안내

이 문서 묶음은 팀원별 기획서와 `edit.md`의 분류 기준을 합쳐, 발표와 프로토타입 제작에 바로 사용할 수 있도록 재정리한 결과물이다.

## 정리 원칙

1. 버전명, 내부 작업 로그, 과한 표현은 제거한다.
2. 서비스명을 `보송 매니저`로 통일한다.
3. `다나와`라는 외부 서비스명은 발표 문서에서 직접 쓰지 않고, `가격 비교형 게이트웨이`, `통합 비교 허브`로 표현한다.
4. 자체 구독 크레딧은 MVP 핵심에서 제외한다. 초기 수익화는 중개 수수료, 커머스 제휴, 파트너 구독 중개로 잡는다.
5. 핵심 경험은 `상태 확인 → 문제 이해 → 해결 방법 → 도구/업체 연결 → 완료 후 주기 등록`으로 통일한다.
6. 공포 마케팅보다 다정한 재시작 톤을 사용한다.

## 파일 구성

| 파일 | 용도 |
| --- | --- |
| `bosong_01_product_plan.md` | 발표용 메인 기획서. 서비스 정의, 문제, 타겟, 핵심가치, MVP, 지표, 리스크를 담는다. |
| `bosong_02_business_info.md` | 사업 정보. 경쟁 구도, 수익 모델, 제휴 구조, 시장 논리, 단계별 확장 전략을 담는다. |
| `bosong_03_branding.md` | 브랜딩 기획. 이름, 슬로건, 톤앤매너, 카피, 디자인 원칙을 담는다. |
| `bosong_04_operations.md` | 운영 정보. 청소 카테고리, 주기 계산, 콘텐츠/용품/업체 데이터 구조, 운영 정책을 담는다. |
| `bosong_05_uiux.md` | UI/UX 기획. 탭 구조, 핵심 플로우, 화면별 요구사항, 와이어프레임을 담는다. |

## 최종 한 문장

보송 매니저는 집안의 청소 상태를 보여주고, 필요한 순간 해결 방법과 도구, 맡길 수 있는 서비스를 연결해 다음 관리 주기까지 이어주는 생활 관리 서비스다.
