# 보송 매니저 운영 정보

## 1. 운영 정보의 목적

이 문서는 제품 안에서 실제로 다뤄야 할 청소 카테고리, 주기 계산 방식, 콘텐츠 구조, 용품/업체 데이터, 운영 정책을 정리한다.

핵심은 다음이다.

```text
사용자가 문제를 발견했을 때,
앱이 문제 이름을 붙이고,
해결 방법과 필요한 도구/서비스를 보여주고,
해결 후 다음 주기로 자동 전환한다.
```

## 2. 청소 카테고리

MVP에서는 너무 많은 카테고리를 만들지 않는다. 사용자가 빠르게 이해할 수 있도록 6개 카테고리로 시작한다.

| 카테고리 | 포함 문제 | 연결 가능 용품 | 연결 가능 서비스 |
| --- | --- | --- | --- |
| 욕실·곰팡이 | 물때, 줄눈 곰팡이, 배수구 냄새, 변기 얼룩 | 물때 제거제, 곰팡이 제거젤, 솔, 장갑 | 욕실 집중 청소, 곰팡이 제거 |
| 주방·냄새 | 기름때, 싱크대 냄새, 후드, 냉장고 냄새 | 기름때 세제, 배수구 클리너, 청소포 | 주방 청소, 냉장고 청소 |
| 침구·빨래 | 침구 세탁, 수건 냄새, 빨래 쉰내, 운동화 세탁 | 세탁조 클리너, 세탁망, 섬유탈취제 | 세탁 수거, 침구/운동화 세탁 |
| 쓰레기·수거 | 분리수거, 음식물, 대형폐기물 | 쓰레기봉투, 배수구망, 음식물 처리 용품 | 문앞 수거, 분리배출 대행, 폐기물 처리 |
| 바닥·공간 | 먼지, 머리카락, 바닥 끈적임, 현관 냄새 | 청소포, 먼지떨이, 롤클리너 | 정기 가사청소, 공간 청소 |
| 가전·해충 | 에어컨 냄새, 세탁조 냄새, 필터, 바퀴/개미 | 필터, 세탁조 클리너, 방충 용품 | 에어컨 청소, 세탁기 청소, 방역 |

## 3. 상태 기준

상태는 과장된 위생 점수보다 설명 가능한 사실 기반으로 계산한다.

| 상태 | 기준 | UX |
| --- | --- | --- |
| 정상 | 권장 주기의 70% 미만 경과 | 과도하게 노출하지 않음 |
| 임박 | 권장 주기의 70% 이상 100% 미만 경과 | 준비물, 짧은 팁, 알림 |
| 지연 | 권장 주기 초과 | 가이드, 용품, 업체 연결 |
| 심각 | 지연 기간이 길거나 사용자가 냄새/곰팡이/벌레를 입력 | 직접 가이드와 전문가 연결을 함께 제안 |

## 4. 주기 계산 방식

### 4.1 기본 원칙

1. 마지막 완료일을 기준으로 다음 권장일을 계산한다.
2. 사용자가 직접 해결하든, 용품을 구매하든, 업체를 연결하든 `해결 완료`가 눌리면 주기가 갱신된다.
3. 실제 외부 서비스 완료 API가 없을 때는 신청일 기준으로 임시 완료 처리한다.
4. 사용자가 직접 날짜를 수정할 수 있어야 한다.
5. 이유를 설명할 수 없는 합성 점수는 쓰지 않는다.

### 4.2 계산 예시

```text
마지막 완료일 + 권장 주기 = 다음 권장일
```

| 항목 | 마지막 완료일 | 권장 주기 | 다음 권장일 |
| --- | --- | --- | --- |
| 욕실 곰팡이 점검 | 7월 1일 | 14일 | 7월 15일 |
| 침구 세탁 | 7월 3일 | 14일 | 7월 17일 |
| 배수구 청소 | 7월 8일 | 7일 | 7월 15일 |

### 4.3 파트너 서비스 신청 시

외부 업체 완료 API가 없는 초기에는 다음 방식으로 단순화한다.

```text
서비스 신청일 + 카테고리별 평균 소요일 = 완료 추정일
완료 추정일 + 권장 주기 = 다음 권장일
```

| 서비스 유형 | 평균 소요일 가정 |
| --- | --- |
| 일반 가사청소 | 1일 |
| 욕실 집중 청소 | 1일 |
| 문앞 수거 | 1일 |
| 세탁 수거 | 2~3일 |
| 에어컨/세탁기 청소 | 1~3일 |

## 7. 가이드 작성 형식

가이드는 블로그처럼 길지 않고, 현장에서 바로 따라 할 수 있어야 한다.

```text
1. 먼저 확인할 것
2. 준비물
3. 단계별 청소
4. 잘 안 지워질 때
5. 하면 안 되는 것
6. 다음부터 덜 생기게 하는 법
7. 주기 등록 또는 완료 버튼
```

### 예시: 화장실 물때

| 단계 | 내용 |
| --- | --- |
| 확인 | 표면이 유리, 타일, 금속, 대리석 중 무엇인지 확인 |
| 준비 | 장갑, 구연산 세제 또는 전용 물때 제거제, 부드러운 수세미 |
| 실행 | 세제를 도포하고 일정 시간 둔 뒤 문지르고 헹굼 |
| 주의 | 염소계 세제와 산성 세제를 섞지 않음 |
| 예방 | 샤워 후 물기 제거, 환기, 2~4주 주기 점검 |
| 연결 | 물때 제거제 보기, 욕실 청소 업체 보기 |

### 8.2 추천 기준

- 문제 유형과 적합도
- 표면 소재
- 난이도
- 가격
- 배송 속도
- 사용자 후기
- 재구매율
- 안전성
- 초보자 사용 편의성

### 8.3 추천 원칙

1. 가이드와 관련 없는 상품을 과하게 노출하지 않는다.
2. 왜 이 상품이 필요한지 설명한다.
3. 광고/제휴/스폰서 상품은 명확히 표시한다.
4. 사용자가 이미 보유한 도구를 등록하면 중복 추천을 줄인다.
5. 구매하지 않고도 가능한 대체 방법을 함께 제공한다.

## 10. 추천 로직 초안

```text
추천 점수 =
  상태 긴급도 30%
+ 문제 적합도 25%
+ 가격 적합도 15%
+ 서비스 가능 지역 15%
+ 후기/품질 지표 10%
+ 제휴 여부 5%
```

제휴 여부는 가장 낮은 가중치로 둔다. 추천 신뢰가 무너지면 장기적으로 전환율이 떨어지기 때문이다.

## 12. Task와 Issue의 구분

| 구분 | Task | Issue |
| --- | --- | --- |
| 의미 | 반복 관리할 일 | 사용자가 발견한 문제 |
| 예시 | 화장실 물때 점검 | 샤워부스 유리에 물때가 생김 |
| 시간성 | 주기적 | 상황 발생형 |
| 결과 | 완료 기록과 다음 주기 | 해결 방법, 용품/서비스, 주기 전환 |

사용자가 Issue를 해결하면 Task로 전환된다. 이것이 보송 매니저의 핵심 루프다.

## 13. 운영 정책

| 정책 | 내용 |
| --- | --- |
