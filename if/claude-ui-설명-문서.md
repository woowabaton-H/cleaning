# 보송 매니저 UI 설명 문서

> 대상 파일: `bosong_manager_prototype.html`
> 목적: 프로토타입 구조를 팀원이 코드 없이도 파악할 수 있도록 정리

---

## 1. 화면 골격

```text
데스크톱/모바일 어디서 열어도 폭 430px 고정 프레임 안에서 동작
프레임 하단에 탭 5개가 항상 붙어 있음(sticky)
프레임보다 화면이 좁으면(실제 모바일) 프레임이 화면 전체를 채움
```

- 프레임 밖 여백은 배경색(`#E7ECF2`)만 깔려 있어 데스크톱에서도 "폰 화면을 보고 있다"는 느낌을 줌
- 탭 전환은 프레임 안에서만 일어나고, 청소하기의 세부 플로우는 같은 프레임 위에 오버레이가 오른쪽에서 슬라이드해 들어오는 방식

---

## 2. 하단 탭 5개

| 탭 | 화면에서 하는 일 |
|---|---|
| 홈 | 오늘 상태 요약, 지연 항목, 10분 청소, 소모품, 최근 기록 |
| 청소하기 | 6개 공간 카테고리 진입점 → 문제 해결 플로우 시작점 |
| 주기보드 | 전체 카테고리를 리스트로, 필터 칩으로 좁혀보기 |
| 커머스 | 문제별 청소 키트 카드 (간단 그리드 수준) |
| 마이 | 설정/기록 메뉴 리스트 (간단 리스트 수준) |

커머스와 마이는 기획서 우선순위(uiux 문서 기준 "간단 포함")에 맞춰 깊은 플로우 없이 목록형으로만 구성함.

---

## 3. 홈 화면 구성 순서

```text
인사말 + 알림 벨
몽글이 인사 카드 (이번 주 요약 한 문장)
이번 주 보송 스탬프 (6칸, 정상/임박/지연 색상)
지금 확인할 항목 (지연 카테고리만 노출)
10분 안에 가능한 청소 (가로 스크롤 카드)
곧 필요한 소모품
최근 해결한 문제
```

지연이 없으면 "지금은 밀린 항목이 없어요" 문구로 대체됨.

---

## 4. 청소하기 딥플로우 (오버레이 4단계)

```text
STEP 1  카테고리의 문제 목록에서 선택
STEP 2  가이드 (먼저 확인할 것 → 준비물 → 순서 → 주의할 것)
STEP 3  비교 (직접 해결 도구 카드 / 맡길 서비스 카드)
STEP 4  완료 (직접 해결 or 업체 요청에 따라 문구 분기, 마스코트 초록 버전 등장)
```

- 완료를 누르면 해당 카테고리 스탬프가 `정상`으로 바뀌고, 홈의 "최근 해결한 문제"에 기록이 쌓임 → 상태 변화가 실시간으로 눈에 보임
- 뒤로가기는 스택 구조라 STEP 3에서 뒤로 가면 STEP 2로, STEP 2에서 뒤로 가면 STEP 1로 돌아감

---

## 5. 상태 색상 규칙 (스탬프·배지 공용)

| 상태 | 색상 | 의미 | UI에서의 행동 |
|---|---|---|---|
| 정상(good) | 그린 `#00C880` | 권장 주기 이내 | 클릭은 되지만 강조 안 함 |
| 임박(soon) | 앰버 `#FFB800` | 곧 주기 도래 | 은은하게 표시 |
| 지연(late) | 블러시 `#FF8FA3` | 주기 초과 | 홈 상단에 우선 노출, 점선 테두리로 강조 |

---

## 6. 마스코트 사용 규칙

- 홈 상단 인사 카드: 파란색 기본 버전
- 완료(STEP 4) 화면: 초록색 축하 버전
- 그 외 화면(가격 비교, 리스트, 설정)에는 등장하지 않음 — 정보 밀도 높은 화면에 캐릭터를 넣지 않는다는 브랜딩 원칙 그대로 따름

---

## 7. 색상 토큰

| 이름 | 값 | 용도 |
|---|---|---|
| Blue | `#3182F6` | 기본 강조, 버튼, 마스코트 |
| Green | `#00C880` | 완료/정상 |
| Amber | `#FFB800` | 임박 |
| Blush | `#FF8FA3` | 지연 |
| Ink | `#191F28` | 본문 텍스트 |
| Gray | `#8B95A1` | 보조 텍스트 |
| Surface | `#F2F4F6` | 카드 배경, 아이콘 배경 |

기존에 만들어둔 다른 프로토타입과 색 토큰을 동일하게 맞춰서 자료끼리 어긋나지 않게 했음.

---

## 8. 데이터 구조 (코드 상 핵심 오브젝트)

```text
CATEGORIES  →  6개 카테고리, 각 2개 이슈
  이슈 하나당: 예상 시간 / 난이도 / 준비물 / 단계별 방법 / 주의사항 / 추천 도구 / 추천 업체
KITS        →  커머스 키트 4종
MY_MENU     →  마이 탭 메뉴 목록
```

카테고리·이슈 데이터를 하나의 배열로 관리해서, 화면 4개(홈 지연카드/청소하기 그리드/주기보드/딥플로우)가 전부 같은 데이터를 참조함 — 어딘가에서 완료 처리하면 나머지 화면에도 자동 반영됨.

---

## 9. 앞으로 채워야 할 부분

| 항목 | 현재 상태 |
|---|---|
| 커머스 상세 페이지 | 목록만 있고 상세/장바구니 없음 |
| 마이 탭 하위 화면 | 메뉴 리스트만 있고 각 항목 클릭 시 이동 없음 |
| 알림 패널 | 벨 아이콘만 있고 패널 내용 없음 |
| 실제 데이터 연동 | 현재 전부 정적 데이터(JS 배열) |
