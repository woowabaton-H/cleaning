# 클린루프 문제 정의 / 방향성 문서

작성일: 2026-07-09  
문서 목적: 청소 주기 관리, 커뮤니티 기반 청소 지식/소통, 청소템 탐색과 서비스 연결의 제품 방향을 정리한다.

## 1. 서비스 한 줄 정의

클린루프는 집안 청소 주기를 색상으로 보여주고, 커뮤니티에서 청소 지식과 생활 질문을 나누며, 필요한 청소템과 청소서비스를 쉽게 고를 수 있게 하는 청소 생활 앱이다.

더 짧게 말하면 다음과 같다.

> 오늘 관리할 일은 놓치지 않고, 막히는 청소 문제는 함께 해결하는 청소 생활 앱

## 2. 배경

청소는 단순한 할 일이 아니다. 침구 세탁, 배수구 청소, 수세미 교체, 욕실 물때 제거, 음식물 처리, 필터 관리처럼 항목마다 주기가 다르고 필요한 도구도 다르다. 사용자는 “청소해야 한다”는 사실을 알아도 무엇부터 해야 하는지, 어떤 방법이 맞는지, 어떤 청소템이 필요한지, 혼자 하기 어려울 때 어디에 맡겨야 하는지를 따로 판단해야 한다.

기존 청소 루틴 앱들은 주기 관리의 필요성을 이미 보여준다. 방과 작업을 나누고, 마지막 완료일과 다음 주기를 기록하면 집안일의 부담이 줄어든다. 다만 사용자가 실제로 막히는 지점은 관리표 안에서 끝나지 않는다. 물때가 생기면 방법을 찾아야 하고, 세제가 없으면 사야 하며, 혼자 처리하기 어려운 일은 서비스를 알아봐야 한다. 지금은 이 흐름이 검색, 쇼핑, 업체 탐색, 기록 관리로 흩어져 있다.

클린루프는 이 흩어진 흐름을 억지로 하나의 루프로 묶지 않는다. 주기 관리는 반복 관리 흐름으로 두고, 커뮤니티는 정보와 소통의 공간으로 둔다. 청소템은 직접 판매보다 “이 문제에는 어떤 도구가 맞는지”를 판단하게 돕는 탐색 기능으로 둔다. 관리자가 작성한 문제 해결 콘텐츠나 주기 상세처럼 실행 선택이 자연스러운 지점에서는 청소템과 서비스로 이어질 수 있게 한다.

```text
주기 관리: 주기 확인 -> 완료 기록 -> 다음 주기 갱신
정보 탐색: 청소 문제 탐색 -> 관리자 콘텐츠 또는 사용자 Q&A 확인 -> 필요 시 청소템 또는 서비스 확인
```

## 3. 핵심 사용자

### 3.1 1차 타겟

바쁜 1인 가구와 2인 이상 공동 생활 가구를 1차 타겟으로 둔다. 이들은 집안일을 직접 해야 하는 시간이 부족하거나, 함께 사는 사람과 역할을 나누는 과정에서 반복적인 마찰을 겪는다.

### 3.2 페르소나

#### 김보송, 27세, 직장인, 자취 3년 차

- 필요하면 청소템을 확인하고, 상황에 따라 전문 서비스도 쓰고 싶지만 매번 새로 찾는 과정이 번거롭다.

- 담당자와 완료 기록이 보이면 대화가 줄고 역할이 명확해질 것이라고 느낀다.

- 청소 지식이 모여 있고, 필요한 청소템까지 바로 확인할 수 있는 앱을 원한다.

## 4. 문제 정의

### 문제 1. 청소 주기는 보이지 않으면 밀린다

청소 항목은 반복되지만 각 주기가 다르다. 매일 해야 하는 일, 매주 해야 하는 일, 한 달에 한 번 하면 되는 일이 섞여 있고, 사용자는 마지막 완료일을 기억하기 어렵다. 그래서 실제 문제는 청소 의지보다 상태 가시성에 가깝다. 지금 어떤 항목이 정상이고, 무엇이 곧 필요하며, 무엇이 이미 밀렸는지가 보여야 행동이 시작된다.

### 문제 2. 청소 지식과 생활 질문은 흩어져 있다

사용자는 물때, 곰팡이, 냄새, 기름때, 먼지 같은 문제를 자주 겪지만 문제별 해결 방법은 흩어져 있다. 어떤 세제를 써야 하는지, 어떤 표면에 쓰면 안 되는지, 어느 정도면 직접 해결할 수 있고 언제 맡기는 편이 나은지 판단하기 어렵다. 동시에 “이 얼룩도 같은 방법으로 닦아도 되는지”, “다들 분리수거를 어떻게 하는지”처럼 정답형 콘텐츠만으로 해결되지 않는 질문도 많다. 클린루프는 관리자가 정리한 콘텐츠와 사용자 질문/답변, 가벼운 잡담이 공존하는 커뮤니티를 제공해야 한다.

### 문제 3. 정보와 실행이 분리되어 있다

청소 방법을 알아도 실행에는 도구가 필요하다. 도구가 없으면 어떤 상품이 맞는지 판단해야 하고, 직접 하기 어렵다면 서비스를 찾아야 한다. 현재 사용자는 정보를 본 뒤 다시 쇼핑몰이나 업체 검색으로 이동한다. 이 과정에서 판단이 끊긴다. 클린루프는 관리자가 작성한 문제 해결 콘텐츠나 청소템 화면에서 필요한 도구와 서비스로 자연스럽게 이어지게 하되, 사용자 질문이나 잡담에는 상품/서비스 연결 흐름을 억지로 붙이지 않는다.

### 문제 4. 함께 사는 집은 역할이 흐려진다

룸메이트, 커플, 가족이 함께 사는 집에서는 청소가 개인 할 일이 아니라 공동 운영 문제가 된다. “누가 해야 하는지”, “지난번에 누가 했는지”, “이번에는 누구 차례인지”가 불명확하면 한 사람에게 기억과 지시가 몰린다. 클린루프는 담당자와 완료 기록을 통해 반복적인 확인과 눈치를 줄이고, 청소를 공유된 상태로 바꿔야 한다.

### 문제 5. 초반 입력이 많으면 시작하기 어렵다

청소 앱은 집 구조와 작업을 모두 세팅해야 한다고 느껴지는 순간 진입 장벽이 커진다. 초기 경험은 완성된 관리표를 요구하면 안 된다. 사용자는 기본 추천 항목을 바로 보고, 필요한 것만 추가하거나 수정할 수 있어야 한다.

## 5. 서비스 핵심 가치

### 5.1 상태를 한눈에 보여준다

대시보드는 청소 주기의 다가오는 정도를 색상으로 보여준다.

| 상태 | 의미 | 색상 방향 | 행동 |
| --- | --- | --- | --- |
| 정상 | 아직 여유가 있음 | 초록 | 과도한 액션을 만들지 않는다 |
| 임박 | 곧 관리가 필요함 | 노랑 | 준비물, 짧은 팁, 미루기 제공 |
| 지연 | 권장 주기를 넘김 | 코랄 | 완료, 방법 보기, 청소템/서비스 연결 |
| 예약/요청 | 외부 도움을 요청한 상태 | 파랑 | 일정 확인, 완료 처리 |

### 5.2 커뮤니티를 정보와 소통의 공간으로 만든다

커뮤니티는 단순 읽을거리가 아니라 청소 정보를 얻고 서로 묻고 답하는 공간이다. 관리자가 작성한 문제 해결 콘텐츠, 초보자 체크리스트, 계절별 관리법이 있고, 사용자가 직접 청소 궁금증을 올리거나 답할 수 있으며, 집안일과 생활에 대한 잡담도 나눌 수 있다. 사용자는 콘텐츠를 저장하거나 댓글을 남기고 도움됨을 표시할 수 있지만, 커뮤니티가 주기 관리의 입력 장치처럼 보이면 안 된다.

### 5.3 정보에서 청소템과 서비스로 자연스럽게 이어진다

관리자 가이드에는 필요한 도구와 맡길 수 있는 서비스를 함께 배치하고, 청소템 화면에는 도구의 사용 맥락과 실제 후기를 집중해서 보여준다. 예를 들어 욕실 물때 콘텐츠에서는 물때 제거제, 부드러운 솔, 장갑 같은 청소템을 보여주고, 직접 하기 어려운 경우 욕실 집중 청소 서비스를 제안한다. 핵심은 상품을 먼저 미는 것이 아니라 문제 해결 방법을 먼저 제공하고, 실행에 필요한 선택지를 옆에 두는 것이다.

청소템은 MVP에서 직접 판매하지 않는다. 장바구니, 주문, 결제, 배송, 환불은 제품 범위 밖으로 두고, 상품 이미지, 브랜드, 가격, 할인율, 후기, 판매처 링크를 통해 사용자가 더 좋은 선택을 하도록 돕는다. 여러 판매처의 가격을 보여줄 수 있다면 좋지만, 실시간 최저가 보장은 핵심 가치가 아니므로 초기에는 가격 예시와 외부 이동 중심으로 검증한다.

### 5.4 완료 기록이 다음 주기가 된다

사용자가 주기 항목을 직접 완료하거나, 서비스 요청 후 완료 처리했을 때 결과는 주기 기록으로 모인다. 완료 시점이 기록되고 다음 점검일이 자동으로 잡힌다. 이 구조가 반복될수록 사용자는 마지막 청소일을 기억하지 않아도 된다.

### 5.5 여러 사람이 함께 쓸 수 있다

가구 단위로 구성원을 초대하고, 작업별 담당자를 둘 수 있다. MVP에서는 담당자 지정과 완료 기록 공유를 먼저 구현하고, 이후 반복 담당 규칙으로 확장한다. 완료 기록은 개인을 압박하기 위한 점수가 아니라 집안 상태를 함께 보기 위한 근거다.

## 6. 포지셔닝

클린루프는 단순 청소 체크리스트가 아니다. 또한 상품만 나열하는 쇼핑 화면이나 업체 목록만 보여주는 서비스도 아니다.

클린루프의 포지션은 다음과 같다.

> 청소 주기를 관리하고, 커뮤니티에서 지식을 나누며, 검증된 청소템과 서비스를 고르게 돕는 청소 생활 앱

경쟁 앱에서 참고할 점은 방/작업/주기/담당자 구조와 색상 기반 상태 표현이다. 클린루프가 다르게 가져갈 지점은 주기 관리, 커뮤니티, 청소템의 역할을 분리하면서도 필요할 때만 연결하는 방식이다. 사용자는 주기 탭에서 “오늘 욕실이 밀렸다”를 확인하고 해결할 수 있어야 하고, 커뮤니티에서는 “욕실 물때를 어떻게 닦는지”, “다른 사람들은 어떤 도구를 쓰는지”를 편하게 탐색하고 물어볼 수 있어야 하며, 청소템에서는 실제 후기와 판매처를 보고 선택할 수 있어야 한다.

## 7. 핵심 사용자 루프

```text
1. 대시보드에서 색상으로 상태를 확인한다.
2. 임박 또는 지연 항목을 선택한다.
3. 짧은 가이드와 필요한 준비물을 본다.
4. 직접 완료, 청소템 확인, 서비스 연결 중 하나를 선택한다.
5. 해결 후 완료 기록이 남고 다음 주기가 잡힌다.
6. 마이페이지에서 청소발자국과 공동 가구 기록을 확인한다.
```

커뮤니티와 청소템은 별도의 탐색 흐름을 가진다.

- 커뮤니티: 관리자 콘텐츠, 청소 궁금증 Q&A, 잡담, 생활 팁, 경험 공유의 공간
- 청소템: 문제별 도구 묶음, 상품 이미지, 브랜드, 가격, 할인율, 판매처, 사용자 후기의 확인점
- 마이페이지: 메뉴를 통해 청소발자국, 히스토리, 구성원별 담당 현황을 확인하는 공간

## 8. 핵심 지표

### 8.1 North Star Metric

월간 청소 완료 기록 수

이 지표는 사용자가 앱에서 실제로 집안 관리 행동을 완료했는지 보여준다. “청소 문제”는 콘텐츠와 검색의 분류 기준으로는 유용하지만, 사용자가 콘텐츠를 읽고 실제로 해결했는지를 자동으로 알기 어렵기 때문에 North Star의 측정 단위로 쓰지 않는다. MVP에서는 사용자가 명시적으로 완료한 주기 항목과 일회성 청소 기록을 기준으로 측정한다.

완료 방식은 직접 완료, 관리자 가이드 확인 후 완료, 청소템 확인 후 완료, 서비스 요청 후 완료, 공동 구성원 완료로 나누어 본다. 콘텐츠와 청소템의 기여도는 North Star가 아니라 보조 지표로 추적한다.

### 8.2 활성화 지표

| 단계 | 지표 | 의미 |
| --- | --- | --- |
| 첫 사용 | 기본 추천 주기 노출 후 앱 둘러보기 완료율 | 초반 입력 부담이 낮은지 확인 |
| 첫 행동 | 첫 주기 완료율 | 대시보드가 실제 행동으로 이어지는지 확인 |
| 주기 생성 | 첫 주기 생성 또는 수정률 | 사용자가 자신의 집에 맞게 조정하는지 확인 |
| 정보 탐색 | 커뮤니티 콘텐츠 조회 후 저장/댓글/도움됨 비율 | 청소 지식이 앱 안에서 가치가 있는지 확인 |
| 커뮤니티 참여 | 질문 작성, 답변 작성, 잡담 댓글 참여율 | 커뮤니티가 단순 콘텐츠 목록이 아니라 소통 공간인지 확인 |
| 실행 연결 | 가이드에서 청소템 또는 서비스 상세로 이동한 비율 | 정보에서 실행으로 자연스럽게 이어지는지 확인 |
| 도움받은 완료 | 가이드/청소템 확인 후 24시간 내 완료된 기록 비율 | 정보와 도구 탐색이 실제 행동에 기여하는지 확인 |
| 청소템 탐색 | 청소템 상세 조회, 판매처 이동, 찜 비율 | 청소템 탭이 선택 전 판단을 돕는지 확인 |
| 공동 사용 | 초대된 가구의 주간 활성 구성원 수 | 여러 사람이 함께 쓰는 가치가 있는지 확인 |

### 8.3 품질 지표

- 완료 버튼 성공률
- 주기 상태 계산 오류율
- 알림 클릭 후 완료율
- 콘텐츠 도움됨 비율
- 청소템 확인 후 완료 전환율
- 서비스 연결 후 완료 기록 생성률
- 공동 작업 담당자 변경 성공률

## 9. MVP 성공 기준

MVP는 모든 집안일을 완벽히 관리하는 앱이 아니라, 핵심 루프가 설득되는지를 검증해야 한다.

성공 기준은 다음과 같다.

1. 사용자가 첫 화면에서 오늘 관리할 항목을 이해한다.
2. 주기 상태가 색상으로 명확히 구분된다.
3. 사용자가 주기를 생성, 수정, 완료할 수 있다.
4. 커뮤니티에서 관리자 콘텐츠, 청소 Q&A, 잡담 글을 구분해 탐색하고 참여할 수 있다.
5. 관리자 가이드에서 청소템과 서비스 연결이 과하지 않게 이어지고, 청소템 화면에서는 도구 선택에 필요한 정보가 충분히 제공된다.
6. 마이페이지에서 청소발자국과 공동 사용 기록을 확인할 수 있다.
7. 초반 입력이 적어도 앱을 둘러보고 첫 완료를 만들 수 있다.

## 10. 이번 문서에서 제외하는 내용

이번 통합 문서는 직접 판매, 결제, 배송, 환불, 외부 서비스 운영 조건을 다루지 않는다. 제품의 1차 설득 대상은 “이 앱이 청소를 덜 막막하게 만들고 실제 관리 행동까지 이어지는가”이다.
