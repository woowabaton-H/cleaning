# 클린루프 요구사항 문서

작성일: 2026-07-09  
문서 목적: 클린루프 MVP의 기능 범위, 화면별 요구사항, 데이터 구조, 검수 기준을 정의한다.

## 1. 제품 개요

클린루프는 청소 주기 관리 앱을 출발점으로 삼되, 커뮤니티에서 청소 지식과 생활 질문을 나누고, 청소템에서 검증된 청소 도구를 고를 수 있게 하는 집안 청소 생활 앱이다.

MVP의 핵심은 네 개의 진입점이다.

| 진입점 | 역할 |
| --- | --- |
| 주기 | 오늘의 청소 상태, 주기 생성/수정/완료 |
| 커뮤니티 | 관리자 콘텐츠, 청소 궁금증 Q&A, 잡담과 경험 공유 |
| 청소템 | 문제별 청소 도구 묶음, 상품 정보, 판매처, 사용자 후기 |
| 마이페이지 | 메뉴를 통한 청소발자국, 히스토리, 구성원 관리 |

## 2. 사용자 요구

### 2.1 개인 사용자

- 오늘 무엇을 해야 하는지 한눈에 알고 싶다.
- 각 청소 항목이 얼마나 밀렸는지 색상으로 보고 싶다.
- 청소 방법을 검색하지 않고 앱 안에서 짧게 확인하고 싶다.
- 필요한 청소템이나 서비스를 자연스럽게 이어서 보고 싶다.
- 다른 사람의 청소 질문, 답변, 생활 팁을 참고하고 싶다.
- 청소를 완료하면 다음 주기를 자동으로 관리하고 싶다.

### 2.2 공동 생활 사용자

- 룸메이트, 가족, 커플과 작업을 나누고 싶다.
- 누가 무엇을 완료했는지 기록으로 확인하고 싶다.
- 담당자 변경과 공동 완료 기록이 필요하다.
- 한 사람이 계속 지시하지 않아도 앱에서 상태가 보이길 원한다.

### 2.3 초보 사용자

- 처음부터 모든 집 구조와 작업을 입력하고 싶지 않다.
- 기본 추천 주기를 바로 보고 필요한 것만 수정하고 싶다.
- 청소 문제의 이름, 원인, 준비물, 주의사항을 쉽게 알고 싶다.

## 3. MVP 범위

### 3.1 포함 기능

- 기본 추천 주기 세트 제공
- 주기 대시보드
- 주기 생성, 수정, 완료
- 상태 색상 표시
- 문제별 짧은 가이드
- 관리자 가이드의 관련 청소템과 서비스 연결
- 커뮤니티 콘텐츠 목록과 상세
- 청소 궁금증 Q&A 목록, 상세, 작성
- 잡담 게시판 목록, 상세, 작성
- 청소템 목록과 상품 상세
- 상품 이미지, 브랜드, 가격, 할인율, 사용자 후기 표시
- 판매처, 가격 예시, 외부 판매처 이동 표시
- 청소발자국과 완료 히스토리
- 가구 구성원 표시와 담당자 배정
- 저장한 콘텐츠, 내가 쓴 글/답변, 찜한 청소템 메뉴

### 3.2 제외 기능

- 직접 판매
- 장바구니, 주문, 결제, 배송, 환불
- 외부 판매처 구매 완료 자동 처리
- 실시간 최저가 보장
- 실시간 업체 예약 확정
- 복잡한 관리자 도구
- 고도화된 자동 판정
- 고도화된 커뮤니티 운영/신고/모더레이션 자동화
- 다공간 전문 관리 기능

MVP에서는 외부 판매처 이동 또는 서비스 요청 예시까지 표현하고, 실제 거래 처리는 범위 밖으로 둔다.

├─ 주기
│  ├─ 오늘의 상태
│  ├─ 주기 카드
│  ├─ 주기 생성/수정
│  ├─ 완료 처리
│  └─ 빠른 해결 시트
├─ 커뮤니티
│  ├─ 관리자 콘텐츠
│  ├─ 청소 궁금증 Q&A
│  ├─ 잡담/생활 이야기
│  ├─ 사용자 경험 공유
│  └─ 검색/태그
├─ 청소템
│  ├─ 문제별 추천 묶음
│  ├─ 청소 도구/소모품
│  ├─ 상품 상세와 사용자 후기
│  ├─ 판매처/가격 옵션
│  ├─ 찜한 청소템
│  └─ 외부 판매처 이동
└─ 마이페이지
   ├─ 프로필/가구 요약
   ├─ 메뉴 목록
   ├─ 청소발자국 메뉴
   ├─ 완료 히스토리 메뉴
   ├─ 구성원 메뉴
   ├─ 담당 현황 메뉴
   ├─ 이번 주 요약 메뉴
   ├─ 내 커뮤니티 활동 메뉴
   └─ 찜한 청소템 메뉴

## 6. 콘텐츠 요구사항

### 6.1 문제 해결 콘텐츠 구조

각 콘텐츠는 다음 구조를 따른다.

| 항목 | 설명 |
| --- | --- |
| 문제명 | 예: 욕실 물때, 배수구 냄새, 세탁조 냄새 |
| 발생 위치 | 욕실, 주방, 세탁실, 침실 등 |
| 난이도 | 쉬움, 보통, 어려움 |
| 예상 소요 시간 | 5분, 15분, 30분 등 |
| 준비물 | 필요한 도구와 대체 가능한 도구 |
| 단계 | 현장에서 따라 할 수 있는 짧은 순서 |
| 주의사항 | 세제 혼합 금지, 환기, 소재 손상 주의 등 |
| 관련 청소템 | 관리자 콘텐츠에서 선택적으로 연결되는 최소 도구 |
| 관련 서비스 | 관리자 콘텐츠에서 직접 하기 어려울 때 선택적으로 연결되는 서비스 |

### 6.2 커뮤니티 게시글 구조

| 유형 | 필수 정보 |
| --- | --- |
| 관리자 콘텐츠 | 제목, 문제명, 공간, 예상 소요 시간, 본문, 관련 청소템/서비스 여부 |
| 청소 궁금증 Q&A | 제목, 본문, 사진, 태그, 답변 수, 채택 또는 도움됨 표시 |
| 잡담/생활 이야기 | 제목, 본문, 댓글 수, 작성 시점 |
| 사용자 경험 공유 | 제목, 사용한 청소템/서비스, 해결된 경험, 사진, 만족도 |

## 8. UX 요구사항

1. 초반에 많은 입력을 요구하지 않는다.
2. 색상은 상태를 설명하기 위한 도구로 사용하고, 사용자를 압박하는 표현은 피한다.
3. 완료는 한 번의 명확한 액션으로 가능해야 한다.
4. 관리자 가이드, 청소템, 서비스 연결은 한 화면 안에서 확인 가능해야 한다.
5. 상세 흐름은 2단계 이상 깊어지지 않게 설계한다.
6. 직접 해결과 맡기기를 동등한 선택지로 표현한다.
7. 공동 사용 기능은 감시나 경쟁보다 역할 가시화에 초점을 둔다.
8. 외부 판매처나 서비스 요청으로 이동하는 항목은 사용자가 구분할 수 있어야 한다.
9. 커뮤니티 Q&A와 잡담에는 주기 추가나 상품/서비스 연결 흐름을 강제하지 않는다.
10. 청소템은 장바구니와 주문 기능을 기대하게 만드는 표현을 피한다.

## 9. 검수 기준

| 항목 | 통과 기준 |
| --- | --- |
| 주기 상태 | 정상, 임박, 지연, 예약/요청이 색상과 문구로 구분된다. |
| 주기 액션 | 생성, 수정, 완료가 모두 가능하다. |
| 커뮤니티 | 관리자 콘텐츠, 청소 Q&A, 잡담이 구분되고 Q&A/잡담에는 상품/서비스 연결 흐름이 강제되지 않는다. |
| 정보 연결 | 관리자 콘텐츠에서 맥락에 맞는 관련 청소템과 서비스로 이동할 수 있다. |
| 실행 연결 | 가이드에서 직접 완료, 청소템 보기, 서비스 보기가 동시에 제공된다. |
| 청소템 | 상품 이미지, 브랜드, 가격, 할인율, 평점, 후기 수와 실제 사용자 후기가 보인다. |
| 판매처 | 외부 판매처, 가격 확인 시점, 외부 이동 여부가 명확히 보인다. |
| 공동 사용 | 담당자와 공동 완료 기록이 보인다. MVP에서는 담당자 지정과 기록 공유까지 검수한다. |
| 히스토리 | 완료 기록이 청소발자국에 누적된다. |
| 초기 부담 | 기본 추천 항목만으로 첫 화면이 비어 있지 않다. |
| 문구 톤 | 죄책감, 과장, 위협을 만들지 않는다. |
