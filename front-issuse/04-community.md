# 4. 커뮤니티 화면

작업 순서: 4번째 (시간 남으면 진행하는 P1 영역)
의존성: 00-foundation
연결 백엔드 문서: `06-community.md`
참고 요구사항: CM-01~16
참고 디자인: design-direction.md 8장

design-direction.md는 커뮤니티를 "이번 요청의 핵심 변경 범위는 아니다"라고 명시한다. 톤만 홈/셀렉션에 맞추고, 우선순위상 홈·셀렉션·마이보다 뒤에 진행한다.

## 4.1 목록 화면 (CM-01~06)

- 세그먼트 컨트롤로 `꿀팁 공유` / `Q&A` 전환 (`GET /community/posts?type=`)
- 카드 구성: 카테고리 아이콘, 제목, 태그, 요약, 도움됨 수, 댓글/답변 수
- 반응이 좋은 글(`isPopular=true`)은 인기 배지로 시각적으로 구분
- 위험 정보가 있는 글에는 안전 배지 표기 영역을 둔다(운영 정책, CM-14 대응 UI 훅만 마련)

문구 예:

- `욕실 물때, 세제보다 물기 제거가 먼저예요`
- `수건 냄새가 남을 때는 세탁조부터 봐요`

## 4.2 상세 화면 (CM-07~11)

구성: 글 유형, 제목, 태그, 도움됨 수, 본문

- 상세에서는 상품 연결보다 해결 방법과 안전 안내를 먼저 배치한다.
- 도움됨 표시 액션 제공 (`PUT`/`DELETE /community/posts/{id}/helpful`, 사용자당 1회 제한이므로 이미 누른 상태는 버튼 상태로 구분)
- 꿀팁 글에는 댓글 작성 진입점, Q&A 글에는 답변 작성 진입점 UI를 배치한다. 다만 **실제 작성 제출 기능은 이번 범위에서 제외**한다 — 백엔드(`06-community.md`)에 댓글/답변 저장 API가 없기 때문이다. 진입점을 누르면 "곧 열릴 예정이에요" 톤의 안내만 표시한다.

## 4.3 저장 (CM-12, P1)

- 글 저장/해제: `PUT`/`DELETE /community/posts/{id}/save`
- 저장한 글을 다시 볼 화면은 이번 범위에 포함하지 않는다(마이 메뉴 확장 없음). 필요해지면 `03-my.md`에 메뉴 항목을 추가하는 방식으로 확장한다.

## 4.4 완료 기준

1. 꿀팁/Q&A 세그먼트 전환과 태그 필터가 동작한다.
2. 인기 글이 배지로 구분되어 보인다.
3. 상세에서 도움됨 표시가 사용자당 1회로 제한되어 동작한다.
4. 댓글/답변 작성 진입점은 보이되, 제출 기능은 없고 안내 문구로 처리된다.
