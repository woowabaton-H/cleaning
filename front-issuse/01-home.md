# 1. 홈 화면

작업 순서: 1번째
의존성: 00-foundation (아이콘 타일, 상태 배지, 토스트, 바텀시트)
연결 백엔드 문서: `02-category.md`, `03-completion.md`, `04-home-summary.md`
참고 요구사항: HM-01~05, CY-01~24, ST-01~05
참고 디자인: design-direction.md 6장

## 1.1 홈의 역할

홈은 기록을 보여주는 화면이 아니라, 오늘 또는 이번 주에 챙기면 좋은 청소 리듬을 보여주는 화면이다. 사용자가 바로 알아야 하는 것은 `무엇을 하면 되는지`, `얼마나 급한지`, `끝나면 어디를 누르면 되는지`다.

## 1.2 화면 구성

1. 인사와 날짜
2. 오늘의 한 줄 제안 (예: `보송님, 오늘은 여기만 봐도 충분해요`)
3. 이번 주 진행 요약 (완료 수 원형 미터는 작게 유지)
4. 주기 카드 목록

`GET /home` 응답의 `message`, `monthlyCompletionCount`, `categories`, `recentLogs`를 조합해 구성한다. `recentLogs`는 목록으로 펼치지 않고 카드 컨텍스트(예: `마지막 7월 1일`)로만 녹여 쓴다.

## 1.3 주기 카드

카드 기본 구성:

```text
[아이콘 타일]  욕실
              오늘 살짝 챙겨볼까요?
              마지막 7월 1일 · 14일 주기

[상태 배지] D+2
[했어요] [도움 볼래요]
```

규칙:

- 최소 높이 112px, 반경 16px
- 카드 전체를 탭하면 상세로 들어간다.
- `했어요`는 가장 빠르게 누를 수 있는 위치에 둔다.
- `주기 바꾸기`는 카드 표면 3번째 버튼이 아니라 상세/더보기에서 제공한다.
- 급한 카드가 위로 오도록 정렬한다(백엔드는 정렬을 주지 않으므로 프론트에서 상태 우선순위로 재정렬: late > due > soon > good).

## 1.4 상태 배지 매핑 (중요)

디자인은 5단계(`late`/`due`/`soon`/`good`/`doneToday`) 상태 배지를 요구하지만, 백엔드(`GET /home`, `GET /categories`)는 `status.code`로 `due`/`soon`/`good` 3종만 내려준다. 5단계는 프론트에서 `daysUntilNext`와 `lastDoneAt`을 조합해 파생 계산한다.

| 프론트 상태 | 판정 규칙 | 카드 색 | 배지 문구 |
| --- | --- | --- | --- |
| `doneToday` | `lastDoneAt`의 날짜 = 오늘 | `fresh-mint` | `오늘 반짝` |
| `late` | `status.code=due` AND `daysUntilNext < 0` | `soft-pink` | `살짝 밀렸어요` |
| `due` | `status.code=due` AND `daysUntilNext >= 0` (오늘 마감) | `clean-blue-soft` | `오늘 좋아요` |
| `soon` | `status.code=soon` | `soft-yellow` | `곧 챙겨요` |
| `good` | `status.code=good` | 흰 카드 + 파란 아이콘 | `아직 여유` |

색상만으로 상태를 전달하지 않고, 배지 문구를 항상 함께 표시한다(ST-05).

## 1.5 인터랙션

### 완료 처리 (CY-06~11)

1. `했어요` 탭 → `POST /categories/{id}/complete` 호출
2. 응답의 `toastMessage`를 기반으로 토스트 표시 (형식은 00-foundation의 토스트 컴포넌트, 예: `✨ 반짝반짝해졌어요 / 다음 주기는 제가 기억할게요`)
3. 해당 카드 상태를 즉시 `doneToday`로 갱신 (재조회 없이 낙관적 갱신 후, 다음 홈 진입 시 서버 값으로 재검증)
4. 이번 주 진행 요약, 최근 기록 컨텍스트도 함께 갱신

### 주기 수정 (CY-12~16)

1. 카드 상세/더보기 진입 → 바텀시트 오픈
2. 3일 / 7일 / 14일 / 21일 / 28일 선택지 제공
3. 현재 마지막 완료일과 다음 관리일을 함께 표시
4. 확인 → `PATCH /categories/{id}` 호출 → 카드 주기/상태 즉시 갱신 + 피드백 토스트

### 카테고리 추가 (CY-17~19)

- MVP 시나리오: 반려동물 카테고리 추가
- `POST /categories`(`presetKey: "pet"`) 호출
- 이미 추가된 경우 `CATEGORY_DUPLICATED` 에러를 받아 "이미 챙기고 있어요" 톤으로 안내 (지적하는 톤 금지)

### 도움 보기 (CY-21~23)

1. 카드의 `도움 볼래요` 탭
2. 셀렉션 탭으로 이동하면서 해당 카테고리 필터를 적용한 상태로 진입 (셀렉션 화면 스펙은 `02-selection.md` 참고)
3. 이동 후 "이 카테고리에 맞는 걸 모아왔어요" 톤의 피드백 제공

## 1.6 홈에서 제거/축소한 것

- `HM-04` 이번 달 기록 리스트는 홈에서 완전히 제거한다. 실제 목록은 마이의 `완료 히스토리` 화면으로 이동한다(`03-my.md` 참고).
- 완료 수 원형 미터는 작게 유지하거나 "이번 주 진행 요약" 형태로 축소한다.
- 카테고리 설명 문구가 카드마다 길게 반복되지 않도록 요약해서 노출한다.
- 알림 배지/알림 진입 버튼은 이번 범위에서 다루지 않는다(00-foundation 참고).

## 1.7 완료 기준

1. 첫 화면에서 급한 카드가 1초 안에 눈에 들어온다(정렬 + 색상 + 배지 문구).
2. `했어요` 클릭 시 트랜잭션 결과가 토스트와 카드 상태로 즉시 반영된다.
3. 주기 수정이 바텀시트에서 완결되고 카드에 즉시 반영된다.
4. 반려동물 카테고리 추가와 중복 방지 안내가 동작한다.
5. 도움 보기가 셀렉션 탭으로 필터를 들고 이동한다.
6. 홈 화면에 "이번 달 기록" 리스트가 없다.
