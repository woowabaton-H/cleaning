# 2. 셀렉션 화면

작업 순서: 2번째
의존성: 00-foundation
연결 백엔드 문서: `05-selection.md`
참고 요구사항: SL-01~18

## 2.1 셀렉션의 역할

브랜드가 고른 상품/서비스를 보여주는 공간이다. 사용자는 `왜 골랐는지`보다 `얼마인지`, `후기가 어떤지`, `어떤 상황에 맞는지`, `제휴인지`를 먼저 알고 싶어 한다.

카드에 담는 정보 우선순위:

1. 상품/서비스명
2. 가격 또는 가격대
3. 평점과 후기 수
4. 카테고리와 타입
5. 간단한 적합 상황
6. 제휴 여부

`고른 이유`는 카드 필수 정보에서 제외하고 상세 화면으로 내린다.

## 2.2 목록 화면 (SL-01~06)

- `전체` + 청소 카테고리별 필터 제공
- 카테고리 필터 선택 시 해당 카테고리 항목 + `전체` 공통 항목을 함께 노출 (`GET /selections?category=`)
- `isHighlighted=true` 항목을 상단 우선 노출
- 항목 유형(`kit`/`product`/`service`/`subscription`)을 태그로 구분

## 2.3 카드 하나의 기준 (중요)

하나의 셀렉션 카드는 하나의 상품 또는 하나의 서비스만 대표한다. 서비스/구독형 항목에 딸린 `providers`(제공업체 후보, SL-09~10)는 부모 카드 안에 리스트로 넣지 않고, 형제 카드로 나란히 렌더링한다.

이건 API 스펙을 바꾸는 게 아니라 렌더링 방식의 문제다. `GET /selections/{id}` 응답의 `providers` 배열을 프론트에서 각각 독립된 카드처럼 반복 렌더링하면 된다.

예:

| 통합형 카드(변경 전) | 분리형 카드(변경 후) |
| --- | --- |
| 문앞 수거 서비스 3곳 | `오늘수거 정기 수거`, `우리동네수거 격주 수거`, `클린박스 맞춤 수거` |

## 2.4 카드 구조

상품 카드:

```text
[아이콘/썸네일]  곰팡이 제거 젤 250g
                욕실 · 용품
                6,900원부터
                ★ 4.8 · 후기 1,240
                타일 줄눈에 바르고 기다리는 젤 타입

[제휴] [초보 쉬움]
[담아두기] [가격 보기]
```

서비스 카드:

```text
[서비스 아이콘]  오늘수거 정기 수거
               쓰레기/수거 · 서비스
               월 9,900원부터
               ★ 4.9 · 후기 3,105
               주 1~2회 문앞 수거

[제휴] [정기]
[담아두기] [예약 가능 보기]
```

카드 규칙(10.3):

- 썸네일/아이콘 영역 필수
- 가격은 제목 다음으로 강하게 표시
- 평점/후기 수 필수 표시
- 제휴 여부 태그 필수
- 추천 이유 블록은 카드에서 제거

> 참고: 현재 백엔드(`05-selection.md`)에는 평점/후기 수 필드가 `provider_options.rating_text`에만 있고 `selection_items`에는 없다. 상품형(kit/product) 카드의 평점/후기 수는 이번 MVP 데이터 범위에서는 비워두거나 `priceText`/`reason` 중심으로 대체 표시하고, 실제 평점 데이터가 필요하면 백엔드 확장이 필요하다는 점을 인지하고 진행한다.

## 2.5 상세 화면 (SL-13~18)

구성 순서:

1. 가격과 후기 요약
2. 이런 상황에 맞아요 (`fitFor`)
3. 사용 전 확인할 점 (구 `reason` → `확인하면 좋은 점`으로 낮은 우선순위 배치)
4. 제휴/가격 변동 고지 (`notice`)
5. 외부 보기 CTA

권장 문구:

- `가격과 후기는 바뀔 수 있어요. 이동 전 한 번 더 확인해 주세요.`
- `클린루프는 선택을 돕고, 결제와 예약은 외부에서 진행돼요.`

## 2.6 인터랙션

- 저장/저장 해제: `PUT`/`DELETE /selections/{id}/save`, 멱등 처리이므로 연타해도 안전. 문구는 `담아뒀어요. 필요할 때 다시 볼 수 있어요.` / `담아둔 목록에서 뺐어요.`
- 상세 진입: 카드 탭 시 바텀시트 또는 상세 화면
- 외부 보기 CTA: `POST /selections/{id}/external-view` → 준비된 `externalUrl`이 있으면 새 창/웹뷰로 열고, 없으면 클릭 이벤트만 기록하고 "곧 연결할게요" 톤으로 안내 (SL-18, MVP는 실제 구매/예약 대신 진입점 역할)

## 2.7 완료 기준

1. 카테고리 필터로 목록이 걸러지고, 하이라이트 항목이 상단에 온다.
2. 셀렉션 카드 하나가 상품/서비스 하나만 나타낸다(제공업체도 개별 카드로 분리되어 보인다).
3. 카드에서 가격과 평점/후기(가능한 범위)를 바로 확인할 수 있다.
4. 저장/해제가 목록·상세에 일관되게 반영된다.
5. 제휴 여부와 가격 변동 고지가 카드/상세 어디에서도 숨겨져 있지 않다.
