# 0. 디자인 파운데이션 & 앱 셸

작업 순서: 0번째 (모든 화면 작업의 선행 조건)
의존성: 없음
참고 요구사항: IA-01 ~ IA-05
참고 디자인: design-direction.md 4장, 5장, 10장

이 문서를 먼저 끝내야 이후 홈/셀렉션/마이/커뮤니티 화면에서 색상·타이포·아이콘·공통 컴포넌트를 매번 새로 정의하지 않는다.

## 0.1 컬러 토큰

| 토큰 | 색상 | 용도 |
| --- | --- | --- |
| `clean-white` | `#FFFFFF` | 기본 화면, 카드 |
| `clean-canvas` | `#F6FAFF` | 앱 바깥 또는 보조 배경 |
| `clean-blue` | `#2F7EF7` | 브랜드, 주요 버튼, 활성 탭 |
| `clean-blue-deep` | `#1D5FCC` | 눌림 상태, 강조 텍스트 |

| `bubble-blue` | `#DCEBFF` | 일러스트 배경, 아이콘 타일 |
| `fresh-mint` | `#E7F8EF` | 완료 상태 |
| `soft-yellow` | `#FFF6D8` | 곧 챙길 항목 |
| `soft-pink` | `#FFF0F5` | 밀린 항목 |

## 0.2 타이포그래피

- 폰트: `Pretendard`, `Apple SD Gothic Neo`, `-apple-system`, `BlinkMacSystemFont`, `sans-serif`
- 카드 내부 제목 15~17px, 보조 문구 12~14px
- 버튼 문구 13~15px, font-weight 800 이상
- 자간 0, hero급 대형 타이틀 카드 내부에서 남발 금지

## 0.3 브랜드 톤 / 문구 원칙

성격: `다정한 생활 메이트`. 지시형(`해야 합니다`), 평가형(`놓쳤어요`), 설명 과잉형, 구매 유도형 문구는 피한다.

원칙:

1. 못한 일을 지적하지 않는다.
2. 다음 행동을 하나만 제안한다.
3. 긴 설명보다 짧은 안심 문장을 먼저 둔다.
4. 완료 후에는 칭찬보다 "다음을 기억해준다"는 메시지를 준다.
5. 가격, 후기, 제휴 여부는 담백하게 표시한다.

길이 기준: 제목 12~20자, 보조 문구 1~2문장/45자 이내, 버튼 2~7자, 토스트 제목 12자/설명 35자 이내.

공통 문구 치환표 (화면별 문서에서 재사용):

| 현재 | 변경안 |
| --- | --- |
| 완료 | 했어요 |
| 주기 수정 | 주기 바꾸기 |
| 도움 보기 | 도움 볼래요 |
| 이번 주에 챙기면 좋아요 | 오늘 살짝 챙겨볼까요? |
| N일 뒤 다시 보면 충분해요 | 아직 여유 있어요 · D-N |
| 셀렉션을 저장했어요. | 담아뒀어요. 필요할 때 다시 볼 수 있어요. |
| 저장을 해제했어요. | 담아둔 목록에서 뺐어요. |
| 카테고리를 추가했어요. | 새 주기도 제가 기억해둘게요. |

## 0.4 카테고리 아이콘 타일

- 크기: 48px 기본(카드 내부), 44~56px 범위
- 반경: 16px
- 배경: 카테고리별 파스텔, 안쪽 아이콘 26~30px, 단순하고 둥근 형태
- 프로토타입 단계에서는 이모지로 시작 가능, 이후 커스텀 PNG/SVG로 교체

| 카테고리 | 아이콘 방향 | 배경 |
| --- | --- | --- |
| 욕실 | 물방울, 샤워기, 스퀴지 | 연파랑 |
| 주방 | 수세미, 프라이팬, 싱크대 | 연노랑 |
| 세탁/침구 | 빨래바구니, 이불, 세탁기 | 연보라/연파랑 |
| 쓰레기/수거 | 작은 봉투, 재활용 박스 | 연민트 |
| 바닥/먼지 | 빗자루, 롤클리너 | 연초록 |
| 계절/가전 | 에어컨, 선풍기, 필터 | 연하늘 |
| 반려동물 | 발바닥, 돌돌이, 패드 | 연핑크 |

## 0.5 공통 컴포넌트

### 상태 배지
색상만으로 상태를 전달하지 않는다. 배지 문구와 카드 배경색이 항상 함께 있어야 한다(ST-05).

### 메뉴 행 (마이 탭에서 사용)
- 높이 56~64px, 행 전체 탭 가능
- 왼쪽 라벨, 오른쪽 요약 값 + 화살표
- 예: `완료 히스토리   이번 달 8개 >`

### 토스트
아이콘 + 제목 + 설명을 분리해서 구성한다.

```text
✨ 반짝반짝해졌어요
다음 주기는 제가 기억할게요
```

### 바텀시트
상세 정보, 주기 수정, 셀렉션 상세, 커뮤니티 상세는 바텀시트(또는 이에 준하는 상세 UI)로 통일한다(IA-03).

## 0.6 앱 셸

- 하단 탭 4개: `홈`, `셀렉션`, `커뮤니티`, `마이`. 모든 탭은 1탭으로 이동 가능해야 한다(IA-01, IA-02).
- 헤더의 알림 진입 버튼(NT-01~03)은 이번 범위에서 제외한다. Notification 백엔드 도메인이 없기 때문이며, 필요해지면 별도 확장 작업으로 추가한다.
- 주요 행동 결과는 토스트 또는 화면 상태 갱신으로 즉시 알려야 한다(IA-04).
- 모바일 360px~430px 폭에서 하단 내비게이션, 헤더, 주요 액션 버튼이 안정적으로 노출되어야 한다(IA-05).

## 0.7 완료 기준

1. 컬러 토큰과 타이포그래피가 프로젝트 전역 스타일로 적용된다.
2. 카테고리 아이콘 타일 컴포넌트가 7개 카테고리에 대해 준비된다.
3. 상태 배지, 메뉴 행, 토스트, 바텀시트 컴포넌트가 재사용 가능한 형태로 준비된다.
4. 하단 탭 4개 라우팅과 빈 화면 셸이 동작한다.
